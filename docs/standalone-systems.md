# 単体作戦とシステム拡張（Issue #213）

## 次のリリースに向けた範囲

2026-10-19に採用した次の5項目を実装する。バージョン番号とRelease公開は別のリリース準備で確定する。

1. **偵察履歴**：敵の最終確認位置・兵科・確認ターンを現在の視認と区別して表示する。自軍が実際に観測した情報だけを蓄積し、未索敵の移動・輸送・撃破・兵站を参照しない。記憶した位置を再索敵して空なら消す。攻撃判定とCPUは現在の視認を使う。
2. **編成プリセット**：作戦別・陣営別に最大3件の名前付き兵科構成を保存・適用・削除できる。現在の配置枠・予算・地形・固定対象・占領兵科を適用時にも検証する。経験と資金は現在のシナリオ・進行から計算する。
3. **単体作戦3本**：港湾争奪・拠点防衛・包囲突破を追加する。既存の保持・生存・撤退目標を使い、出撃前の目標・期限・補給方針と対象喪失などの結果を確認できるようにする。
4. **観戦分析**：CPU観戦と全体視点のリプレイで、部隊数・収入・損失の推移とターン要約を確認する。通常のプレイヤー視点へ敵の全体情報を露出させない。
5. **対称マップ生成**：サイズ・海域量・seedを指定し、地形・施設の所有・初期兵力を180度回転対称に生成する。陸路、施設への到達、海がある場合の港と航路を検証する。同じ設定から同じ定義を生成し、カスタム作戦として保存・再利用できるようにする。

## 設計方針

- 偵察履歴と観戦分析は既存の初期状態・コマンド履歴から再構築する表示情報とし、保存・再開・取り消し・リプレイの途中位置で再現する。過去の表示へ未来の観測を持ち込まない。再構築とキャッシュの量に上限を設ける。
- 旧セーブ・旧リプレイは記録された規則を使う。新しい作戦と生成したマップはシナリオスナップショットへ固定する。既存キャンペーン10作戦・通常11マップの定義は維持する。
- プリセットは独立した版付きローカル保存として、JSON構造・名称・兵科・件数・サイズを検証する。保存失敗・不正データは通知し、進行中の対局とキャンペーン進行を保持する。
- 初版の生成マップは16×12・20×16・24×20、海域なし／沿岸／海多めの選択を用意する。施設・部隊の対応と進軍路を保証し、既存の後攻補償を参考に開始資金を設定する。先後の勝率が完全に等しいとは仮定せず、陣営交換のCPU対戦で偏りと未確認範囲を記録する。
- 編成画面、戦域選択、盤面付近の折り畳みパネルへ操作をまとめる。PC・タッチ・キーボードで利用でき、モバイルでマップの横幅を押し広げない。

## 実装内容と確認記録

- 実装前の設計コミットは `fd85d6de05480d39770dc3b925bb1f0fa665640d`、ドラフトは [PR #216](https://github.com/kumakumapon/MiniStr/pull/216)。回帰テストの追加・実行は利用者から承認済み。
- 偵察は両軍それぞれの可視情報をコマンドの先頭から蓄積する。記憶するのは兵科・位置・確認ターン・手番。現在の耐久・兵站や未観測の撃破は記録を更新する根拠にしない。現在の視界外の記録を最大256件保持し、盤面の破線「?」とリストに表示する。
- 取り消し・履歴の分岐・リプレイの後方シークでは観測を再構築する。前方の再生・通常操作は最後の処理位置から追加する。観測・分析は保存の初期状態と操作履歴から復元でき、セーブ／リプレイのschema v4とゲームルールv6を維持する。
- 観戦分析は全体視点のときだけ返す。部隊数は輸送中を含む現役部隊、収入は各陣営の記録値、損失は実際の部隊消失を集計する。撤退・合流を損失へ加算しない。グラフと数値表は最大256ターン、要約は直近8ターンを表示する。
- プリセット保存は `ministr.deployment.presets` のschema v1、名前24文字、各作戦・各陣営3件、全体192件、JSONは256,000バイト以内。適用時に作戦の配置・地形・目標の変更と現在の編成条件を検査する。全データのバックアップ・復元にも検証付きで含める。
- 生成v1のseedは英数字・ハイフン・アンダースコア1〜24文字。海域量は外周の海の幅で変え、内陸の複数進路と両軍の港を結ぶ航路を確保する。生成後に対称性・全施設への車両到達・初期兵力・港間の航路を検査し、通った定義だけをカスタム作戦へ保存する。

| 追加作戦 | 目標 | 易しい敵を相手にしたCPU攻略 |
| --- | --- | --- |
| 港湾争奪戦 | 中央港 (8, 4) を占領して2回連続保持。占領後は艦艇でも守れる | 赤軍の難しいCPUが9ターン目に保持達成 |
| 二つの要衝を守れ | 自軍都市 (6, 5)・(6, 8) を地上部隊で5回連続保持 | 同5ターン目に保持達成 |
| 包囲網を突破せよ | r1・r2・r3から2部隊を (15, 5)・(15, 8) へ撤退 | 同6ターン目に撤退達成 |

いずれも期限は60ターン。既存キャンペーン10作戦と通常11マップの定義は維持する。

### 生成マップの小標本対戦（2026-10-19）

16×12、生成seed `seed-1`〜`seed-3`、各対局は初期状態の既定ダメージseed、最大60ラウンドで比較した。元の後攻補償+2000Gで15局・14,138コマンドを合法に実行した。各海域のseed-1では難易度の陣営を交換して、赤難しい／青普通は赤、赤普通／青難しいは青がそれぞれ勝利した。

| 海域 | 普通対普通の3局（赤／青の勝利） | 補償+4000Gの比較（赤／青） |
| --- | --- | --- |
| 海域なし | 2／1 | 2／1 |
| 海域少なめ | 3／0 | 3／0 |
| 海域多め | 2／1 | 2／1 |

補償増額の9局でもこの標本の勝敗数の改善は確認できず、初版は+2000Gを維持する。これは小標本であり、全seed・全サイズ・人間同士の先後の公平性を保証する結果ではない。特に沿岸の3局は赤軍勝利に偏っており、今後の比較対象として残す。大きなサイズのCPU確認は、全3サイズ×3海域の各12ターン、難易度の陣営交換で行う。
