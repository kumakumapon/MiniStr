# v1.5.7

## 峡谷の関門で出撃前配置

単体作戦「峡谷の関門」（20×16）で、兵科だけでなく地上4部隊の出撃位置を選べます。出撃準備の「出撃前編成：兵科・配置・予算」を開き、区域プレビューと各枠の「出撃位置」で配置してください。

- 赤軍：X1〜4 / Y2〜5。青軍：X17〜20 / Y12〜15。表示座標は1始まりです。
- 航空枠r5/b5の位置は固定。兵科変更は従来どおりです。
- CPU対戦では赤軍だけ、交代対戦・CPU観戦では両軍を配置できます。
- 空いている合法なマスを候補とし、重複・区域外・固定位置の変更を拒否します。
- その軍の位置だけを戻す操作と、編成全体を既定へ戻す操作を用意しました。

統合戦術ON/OFFの現行単体版が対象です。キャンペーン・日替わり・編集/共有マップ・旧版の配置編集には広げていません。

## 保存・プリセット

確定配置は対局の初期状態へ保存し、保存再開・リプレイでも同じ位置を使います。既存の兵科プリセットは位置を保存せず、適用した軍だけ既定位置へ戻します。

戦闘・勝敗規則、AI、地形、開始時補償、ルールv14、保存/リプレイschema4、campaign schema5、依存版を維持します。

## 比較と提供範囲
