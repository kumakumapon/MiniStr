# MiniStr v1.4.0

## 追加・変更

- タイトルに通常戦・単体作戦向けの「統合戦術」を追加。
- 隣接直接射撃を開始HPによる同時損害に変更。攻撃側+3%、合法な反撃は撃破されても発射。双方の終局条件が同時成立すると引き分け。
- 未移動・未行動の地上部隊が、通常行動の代わりに直接武器で待伏せ。移動指令の開始時に未視認だった敵との実接触で1回射撃し、その会敵射撃への自動反撃は行わない。
- 地上部隊の山岳軽減を満HPで+5ポイント。地形・陣地由来の軽減上限45%、平原・森・道路の差は保持。
- 晴れ／雨を2ラウンド単位で更新し、次ラウンド予報を表示。雨は通常視界−1（最低1）。初版では飛行禁止・移動コスト・ソナーへの天候補正は付けない。
- 視認済みの地上直接戦闘兵科が隣接4マスにZOCを形成。地上部隊は進入で移動終了し、開始マスからは離脱可能。未視認敵・航空・海上からのZOCは付けない。
- 潜水艦と魚雷、駆逐艦の対潜爆雷を追加。潜航は行動を消費し、通常の可視マスでも探知されなければ非表示。駆逐艦は3マス、潜水艦は2マスで探知。3回の自軍手番開始または入港で自動浮上。
- マップのsnapshot差分として、追加の進軍路、前進時の森林、補給地点を配置。公開済みの元定義・生成seedを保持。
- CPUの損耗価値・支援射撃・待伏せ・潜航・護衛／対潜生産と輸送判断を対応。
- 新しい通常戦・単体作戦は、輸送車・輸送艦・輸送ヘリの移動後降車が可能。降車後は両者とも行動終了し、同じ手番の連続輸送・降車後攻撃／占領は行わない。
- 同時射撃・待伏せの演出、日英操作、引き分けの結果／保存／リプレイを対応。

## 互換性と適用範囲

新しい通常戦・単体作戦は規則v13、統合戦術の有効項目と天候seedはsnapshotへ記録。旧対局は記録した規則のまま再現する。キャンペーン・日替わりの標準条件はv12を継続。保存／リプレイのコンテナschemaは4を保持する。

統合戦術は選択式。ZOC停止や降車自体では待伏せを自動発射しない。潜航艦は地上ZOCを作らず、攻撃には探知と対応武器が必要。駆逐艦は統合戦術の潜航有効時、対空副武器に代えて爆雷を使用する。

比較結果・確認済み範囲は[公開前確認](../reviews/2026-11-01-v1.4.0.md)に記録する。正式公開はPRの完了・CI・mainへのマージ後に行う。
