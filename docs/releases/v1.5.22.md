# v1.5.22

参加軍を選べる複数軍対局、途中の人間／CPU切替、固定チーム戦と水域マップを追加しました。

- 緑の国境の3軍北側配置を調整し、4軍の地形の鏡像を統一しました。3・4軍の先手は毎ラウンド交代します。
- 小型「前哨基地強襲」18×14、水域「交差海峡」17×15、新広域32×32を追加しました。任意の2〜4軍が参加できます。
- 固定チームの通常視界共有とチーム勝利に対応しました。資金・施設補給・操作は軍別です。
- 対局中に生存軍の担当を人間／CPUへ切り替えられます。保留中CPUを取り消し、残り行動と切替履歴を保存します。
- 水上艦、搭載・上陸、港の生産・補給、工兵の架橋・破壊に対応しました。
- 新規3軍短期戦は21R、2・4軍は20Rでチームの施設数→HPを判定します。同点は引分です。
- CPU v6は3軍の優先相手と終盤の進軍先を限定改善しました。
- 旧保存・旧CPU・従来広域32×32と通常2軍の規則を維持します。新規則はengine5・経路3・保存schema6で識別し、全履歴から検証します。

20〜30分は試遊目標です。配置・手番の公平性と長期対局は比較結果の範囲で評価し、未解消条件を継続課題に残します。潜水艦・動的な同盟変更・途中参加は含みません。
