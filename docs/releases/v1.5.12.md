# v1.5.12

## 4軍専用32盤面・初期条件・部隊上限

4方向に同じ地形・施設・初期戦力を持つ固定32×32マップ「四方の前線」を追加しました。各軍8部隊、基本資金10,000、司令部・工場・空港・都市2から開始し、全軍の初回手番に同じ収入を適用します。

上限は各軍16・合計64部隊。搭載中も数え、CPUとエンジンで上限超過の生産を拒否します。8・12・16/軍の比較と、3ブラウザの実Workerによる進行・取消を確認しました。

上限ルールと開始域はengine2・4軍schema2へ記録し、命令履歴から照合して再開できます。従来の4軍schema1、2軍の規則/CPU/保存、研究形式を維持します。

本版はマップ・初期条件・上限の基盤APIまでです。4軍の開始メニュー・観戦画面、公開用保存/リプレイ/バックアップと公平性・長期性能の判定は次段階です。
