# v1.5.19

4軍の操作改善・自由割当・陸戦規則

- 生産先切替・連続生産・不可理由、攻撃せず確認できる敵別予測、未行動判定、占領・補給・陣地表示を改善。
- 第1〜第4軍を人間／CPUへ自由に割当。人間2軍＋CPU2軍、人間3軍＋CPU1軍、全軍人間操作に対応。同端末交代とCPU区間は盤面を隠し、各軍の視界を保持。
- 新規対局に広域偵察・工兵の陣地設営・兵站指示、同時射撃・待伏せ・地形防御・天候・ZOCを追加。従来規則／戦術OFFも開始時に選択可能。
- CPU v4と新しい軍別割当付き保存を追加。旧保存の規則・経路・CPU版、完全履歴の検証、停止再開、専用2枠・65,536命令／8MBを維持。

固定32盤面・4軍全参加・全軍敵対・各軍16部隊を維持します。2軍の戦績・キャンペーンには反映しません。
