# v1.5.8

## リプレイから研究対局

終了済みリプレイの赤軍手番開始で「ここから研究対局」を押すと、その局面から人間赤軍／CPU青軍で別の指示を試せます。青軍の研究用方針を選び、同じ分岐点から何度でもやり直せます。元リプレイの規則・状態・分岐までの履歴を保持し、未来の命令を研究側に持ち込みません。

## 専用保存と成績の分離

研究には専用の自動・手動2枠と、研究JSONの取込・書出しを用意しました。終了結果も保存・再開できます。研究での勝敗は単体作戦記録、日替わり成績、キャンペーン進行に反映しません。

研究形式は独立した `ministr-research` schema1です。通常セーブを上書きせず、未知版・破損した研究枠は元データを保全します。全データバックアップに研究を含めます。研究入りバックアップを旧版で復元することはできません。

初版の分岐対象は赤軍手番開始のみです。青軍操作や任意の途中位置からの分岐、複数枝の比較画面は含みません。戦闘・AI・勝敗規則と通常の保存／リプレイschema4は維持します。
