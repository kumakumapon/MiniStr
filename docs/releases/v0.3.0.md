# v0.3.0 リリースノート

- 対象タグ: `v0.3.0`。タグはリリース準備PRをマージしたコミットに付け、公開Releaseに完全なコミットSHAを記載してください。
- 変更内容の確認対象SHA: `32a4f862a378024bec3a1c8335c32e60bbe27080`（PR #181 マージ後の `main`）。準備PRではバージョン表記と本ノートのみを更新します。

## 主な変更

- ユニットが向かい合って攻撃・反撃するバトルシーンを追加。発射、着弾、ダメージ、撃破をアニメーションで表示します。
- 占領・補給・修理のアクションシーンを追加。視界外のユニットや補給元の情報を隠す制約を維持します。
- オリジナルBGMと効果音を改善。戦闘時は専用BGMへ切り替え、発射・着弾・反撃・撃破の効果音を演出に同期します。効果音／BGMのチェックが有効・無効の状態と一致するよう修正しました。
- 盤面の生産施設から生産メニューを開けるようにしました。空いている施設を切り替えて連続生産でき、メニューを閉じてもページと盤面のスクロール位置を保持します。スマートフォン下部にも「生産」ボタンを追加しました。

## 互換性・既知の制限

- v0.2.0 からゲーム規則・セーブ／リプレイ形式・保存キーは変更していません。セーブ／リプレイはschema v4、キャンペーン進行はschema v3です。10ステージのキャンペーン、CPU対戦、ホットシート、エディタなどの既存機能を維持します。
- 音声はブラウザーの自動再生制約に従い、ユーザー操作後に再生されます。BGMと効果音は個別に無効化できます。
- セーブはブラウザーのローカルストレージに保存されます。オフラインでの再起動は保証しません。英語訳と実機アクセシビリティ評価には未完了項目があります。実際のiOS／Android端末での音声・タッチ操作は未検証です。
- 開発依存には GHSA-82fw-gwwq-j7x9 の期限付き例外が残っています。2026-10-16までにVitest 4移行を再評価します。詳細は[依存・配信レビュー](../reviews/2026-10-02-dependency-delivery.md)を参照してください。
- 旧版へ戻す前に、必要なセーブをバックアップしてください。GitHub Pagesは `main` に追随するため、タグの作成だけでは公開画面は切り替わりません。
