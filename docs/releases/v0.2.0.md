## 主な変更

- セーブ・リプレイ形式の検証と旧データ移行を強化し、カスタムシナリオのスナップショット、全データのバックアップ／復元、保存領域の使用量表示を追加。
- シナリオエディタに描画・対称編集・Undo/Redo・プレイ可能性検査を追加。キャンペーンは10ステージ、S/A/B/C評価に対応。
- CPUの判断、戦闘予測、勝敗条件、輸送・補給ルールと回帰検証を改善。日本語／英語の表示切替、盤面操作、リプレイのシーク・視点切替を追加。
- 効果音に加えてオリジナルBGMを追加。地形11種とユニット15種のピクセルアートを更新。

## 互換性・既知の制限

- セーブ／リプレイはschema v4、キャンペーン進行はschema v3。サポート対象の旧形式は移行して読み込みます。過去の対局データは記録時のルールを維持します。
- セーブはブラウザーのローカルストレージに保存されます。オフラインでの再起動は保証しません。英語訳と実機アクセシビリティ評価には未完了項目があります。
- 開発依存には GHSA-82fw-gwwq-j7x9 の期限付き例外があります。2026-10-16までにVitest 4移行を再評価します。詳細は[依存・配信レビュー](../reviews/2026-10-02-dependency-delivery.md)を参照してください。
