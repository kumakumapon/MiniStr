## 主な変更

### 前線補給所

- 歩兵系で占領できる施設を追加しました。自軍の手番開始時に、施設上と隣接1マスの自軍地上部隊を燃料・全武器の弾数上限まで補給します。範囲内の地上輸送車に搭載された部隊も対象です。
- HP修理・収入・生産はありません。航空機と艦船は従来の対応施設で補給します。
- 施設の占領、支配・保持目標、エディタに対応し、既存マップの配置は維持します。

### 工兵と防御陣地

- 工兵を3000Gで生産できます。歩兵系として占領・輸送に対応します。
- 未移動・未行動の工兵は、現在地の平原に500Gを使って陣地を設営し、移動と行動を終了します。各軍同時に4か所まで設営できます。
- 陣地を所有する軍の地上部隊は防御★+1、合計上限4となります。航空機には適用せず、元の地形と移動コストは変えません。
- 敵地上部隊が陣地を通過・進入・降車すると陣地は消失します。隠れた敵との接触で移動が止まった場合は、その先の陣地を消しません。航空機の通過では消失しません。
- 設営の確認・中止・Esc、取り消し・保存再開・リプレイに対応します。陣地は視認できる範囲だけ表示します。

### 単体作戦2本

- **補給拠点争奪**：18×14。2か所の補給所の所有による支配得点を競い、16点で勝利します。後攻の開始資金補償は2000Gです。
- **峠の補給線**：18×14。指定補給所の所有と地上部隊の配置を維持して8ターン保持を目指します。敵軍は同拠点の奪取・2ターン保持などで勝利し、期限は60ターンです。
- 単体作戦は計9本になります。出撃前編成・プリセット・戦績・追加チャレンジ・エディタへ接続し、既存7作戦、通常11マップ、キャンペーン10作戦の定義は維持します。

### 補給表示とCPU

- マップ近くで、選択した自軍兵科の補給範囲を切り替えられます。ユニット情報には、現在地と補給源が維持された場合の次手番の補給見通しを表示します。部隊情報とマップの距離は12px以内を維持します。
- 敵の正確な弾薬・燃料や未索敵の部隊・陣地は公開しません。
- CPUは補給所への帰還、陣地の防御効果、工兵の生産と設営を評価します。公開目標と視認済みの接近敵を使い、攻撃・占領・占領部隊の通路を優先します。

## 保存互換性と既知の制限

- 新規対局は `ruleVersion: 8` です。旧対局は記録されたルールを維持し、v7以前への工兵・補給所・陣地の混入を拒否します。セーブ／リプレイとキャンペーン進行のschema v4は維持します。
- v0.8.0以前のアプリはルールv8の対局を読み込めません。旧版へ戻す前に必要なデータを全データバックアップへ書き出してください。
- **先攻寄りの傾向は残っています。** 争奪戦の確認用20局は赤12勝／青8勝、同難易度だけでは赤8勝／青4勝でした。補償3000G／4000Gでは一貫した改善がなく、2000Gを維持します。防衛戦は意図的な非対称作戦です。
- 生成マップの既定編成には新施設・工兵を追加していません。旧ルールv7／新v8各72局は時間以外の結果が全件一致し、各版とも赤40勝／青32勝でした。新施設・工兵を配置した生成対局の公平性まで確認したものではありません。
- 回転・難易度交換など対応のある対局と同一条件の再実行を、独立標本として加算しません。全seed・全難易度・人間同士の公平性は未確認で、[Issue #213](https://github.com/kumakumapon/MiniStr/issues/213)で継続します。
- PC1280×800とスマートフォン幅390×844で主要操作を自動検証し、画面4枚を確認しました。実機iPhone／iPadのタッチ操作は未確認です。ブラウザ検証はChromiumの主要導線とFirefox／WebKitの互換性確認を含みます。
- 依存パッケージと音楽素材は更新していません。2026-10-21の実装PR最終CIの `npm ci` は **high 1件** を報告しました。該当パッケージ・advisory・修正版・配布物への影響は未特定で、[Issue #168](https://github.com/kumakumapon/MiniStr/issues/168)に記録しています。独立した最新 `npm audit` は今回実行していません。過去の監査0件を今回の結果として扱いません。
- GitHub Pagesは `main` に追随し、タグ固定のプレイ画面ではありません。タグ時点のコードはGitHub Releaseのソースアーカイブを参照してください。
