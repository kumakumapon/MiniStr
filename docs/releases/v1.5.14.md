# v1.5.14

## 4軍の長期記録・比較検証

4軍の保存・JSON・再開を65,536命令/8MBへ拡張しました。新schema2は命令を辞書・数値列で圧縮し、旧schema1も読み込めます。全履歴の検証と進捗・取消、検証済みチェックポイント、上限付きリプレイキャッシュを接続し、同じ記録の再書出しを高速化しました。全データバックアップの長い4軍履歴も中断可能な事前検証へ対応します。

固定した88条件で全24手番順・複数seed・軍別難易度/方針・1,000ラウンド継続を比較しました。同設定72条件では50勝利/22未決着、軍別勝利は16/13/6/15、手番位置別は15/12/11/12。未決着を引き分けへ変えず、軍別差と停滞を継続課題として明示しています。CPUとゲーム規則は変更していません。

次の4軍残件は、未決着と軍別差の原因特定・限定CPU改善、実機と2/4時間の継続測定です。
