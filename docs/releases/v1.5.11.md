# v1.5.11

## 複数敵CPU・Worker取消

4軍の実対局基盤へ、軍別の可視情報で判断するCPUとWorkerを接続しました。敵3軍への射撃、占領・防衛・補給/修理・輸送・生産を扱い、軍別の難易度と方針を設定できます。敵の隠れた部隊・資金・乱数をCPUへ渡さず、視界外の占領進捗も伏せます。

停止・終了・対局切替・設定変更で計算を取消し、要求ID・世代・手番の古い返信を適用しません。命令は適用前に実盤面でも検証し、適用した命令だけを保存履歴へ残します。100ラウンド停止と明示再開も接続しました。

本版はCPU・Workerと進行管理のAPI提供です。専用32盤面、4軍観戦画面、公開用保存/リプレイ操作とバックアップは次段階です。既存2軍のCPU・規則・操作・保存形式は維持します。4軍の公開部隊上限・難易度の勝率順・公平性/性能は今後の比較で確定します。
