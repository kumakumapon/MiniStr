# v1.4.3

## 改善

- 390幅を含む盤面選択で、不要なスクロール書き込みと再配置を削減。翻訳・モーダル属性を更新してからスクロールとフォーカスを復元します。
- Chromeのタッチで最初のタップが選択にならないケースを修正。クリック確定前にユニット情報が広がって盤面が動くことを防ぎます。
- CPU応答の完了・失敗・取消後にWorkerの処理関数を解除し、処理済みの対局状態を保持し続けないようにします。
- リプレイの表示とシーク処理で同じ指令記録を共有し、全指令の二重保持を解消します。
- 長時間CPU観戦・画面往復・長いリプレイのメモリと、PC／390幅・16／32盤面の操作応答を再測定できるスクリプトを追加します。

ゲーム規則・CPU判断・マップ・保存／リプレイ形式は維持します。指令履歴を削る最適化は行いません。
