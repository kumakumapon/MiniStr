# v1.2.2

CPUの補給合流・連携攻撃と、画面復帰後の音声再開を改善します。

- 標準・上級CPUで、残弾・燃料が少ない部隊と補給車を合流させ、次手番の補給まで位置を維持。物資の少ない車両・輸送中の車両・護衛／撤退対象を優先任務から外しません。
- 守勢CPUは、今すぐ射撃できる砲兵を前衛より先に行動させ、敵のHPと反撃力を削ってから前衛が攻撃。見えない敵の情報や将来の仮定の移動は使いません。
- 別タブ／別アプリ・ページ復帰時に、操作で有効化済みのBGM・効果音を再開。iOS系の遅い音声中断通知にも対応。ミュート・音量・現在の曲と位置を維持し、終了済みの戦闘曲を再演奏しません。再開と同時に発生した効果音は250ms以内の最新1件だけ再開後に鳴らし、古い効果音は捨てます。

## 互換性・制限

規則v12、対局・リプレイschema4、キャンペーンschema5を維持。既存の保存・記録済みリプレイを読み込めます。CPUの今後の判断は変わりますが、記録済み指令、戦闘規則、先後補償、生成seedは変更しません。規則v11以前のCPU判断への追加は行いません。

ブラウザ／OSが自動再開を拒否した場合は、復帰後のタップ・キー操作で再試行します。実機iPhone／iPadは低優先度・未確認です。最終の別seed比較では守勢の勝利が36局中3→7に増えた一方、同方針の標準対初級は18局中12→11勝でした。攻勢優位と一部条件の悪化は残ります。CPU比較の結果と既知制限は[確認記録](../reviews/2026-10-31-v1.2.2.md)を参照してください。
