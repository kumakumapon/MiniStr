# v1.2.1

CPU観戦・大盤面の操作応答と保存データの保護を改善します。

- CPU思考を別スレッドで実行し、一時停止・画面移動時に計算を停止。遅れて返った結果やエラーを別の対局へ適用しません。
- 観戦の一時停止・追従・全体表示ボタンを描画間で保持し、CPU連続行動中のクリックを安定化。
- 視界・移動範囲・危険域・地形表示の重複計算と、隠れている盤面の履歴処理を削減。
- 取り消し用の完全盤面の保持数を盤面サイズに応じて制限。32×32は8件を保持し、古い手は指令から再現します。取り消せる範囲は維持します。
- 別タブの保存変更を、書き込み直前やタブ復帰時にも確認。競合時に古いタブの保存データと現在の未保存対局をそれぞれ書き出せます。
- 破損セーブの元データを書き出し、セーブ／バックアップ中の正常な対局だけを新規スロットへ救出する導線を追加。
- Vite 8のmodule metadataを使う配布UI検証に対応し、WebKitの観戦操作の回帰を修正。
- CPU Worker応答・外部マップの検証と、作戦準備画面などのHTML描画の境界保護を強化。

## 互換性・注意点

ゲーム規則v12、対局・リプレイschema4、キャンペーン進行schema5を維持します。既存の保存・記録済みリプレイを読み込めます。CPU判断の規則・重み、生成seed、BGM、マップの仕様はv1.2.0から変更しません。

救出は正常な対局を追加する機能で、戦績・キャンペーン進行・設定の統合や、任意の破損JSONの修復ではありません。現在のカタログで検証できない対局は除外します。元ファイルは保持してください。localStorageの完全同時書き込みを原子的に直列化する保証はありません。

古い取り消しはメモリ削減と引き換えに再現計算が必要です。計測では開始処理と観戦中の最大応答間隔が改善した一方、観戦p95と選択操作は改善を確認していません。実機iPhone／iPadの確認は低優先度・未実施です。
