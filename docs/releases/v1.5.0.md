# v1.5.0

## 補給・修理の運用指定

新しい有限補給の通常戦・単体作戦では、「部隊・兵站一覧」から部隊ごとに補給順（通常／優先）、物資配分（弾薬／燃料優先）、修理（実施／保留）を指定できます。行動を消費せず、その部隊の次回補給・修理へ適用します。

「修理後に残す資金」は0〜1,000,000Gで指定します。修理の支払いだけを制限し、生産には利用できます。対応施設の無料の弾薬・燃料補充は修理保留中も行います。HP修理上限・物資容量・補給範囲・消費単価は従来どおりです。

優先部隊同士は搭載部隊、ID順で配分し、弾薬優先は主武器→副武器→燃料、燃料優先は燃料→主武器→副武器の順です。優先部隊は通常部隊より先に処理します。修理は従来の部隊順です。設定の変更は自軍手番中に行い、保存・取り消し・リプレイへ記録します。CPUも燃料不足・空の武器を自軍情報から判定し、同じ指定を使用します。

## 部隊・兵站一覧と新作戦

自軍の全現役部隊を、損傷・弾薬不足・低燃料・補給見込み・未行動で絞り込みます。行動済みや搭載部隊も表示し、搭載部隊を選ぶと輸送部隊へ移動します。次手番の見込みは現在位置・施設所有・収入を仮定した条件付きの値です。

「戦術演習・限られた物資」を追加しました。中央都市を占領し、地上部隊で4回連続保持します。期限は30ターン。補給指定・修理予算・補給・修理・生産を任意の学習課題として確認できます。学習課題は勝利の追加条件ではありません。

## 互換性

新規の対象対局はルールv14。旧保存・リプレイは記録された規則で再現します。旧版アプリはv14を開けません。キャンペーン・日替わり・従来の無制限補給の規則は保持します。一覧は旧対局でも使えますが、運用指定はv14で利用できます。セーブ・リプレイのコンテナschema4を維持します。
