# v1.4.6

## CPUの守勢・兵站

- 守勢の大きく損傷した部隊が、今の移動だけでは届かない修理拠点へも戻れるようにしました。自軍の資金・対応施設・通行可能な経路を確認します。
- 補給車は、残りの物資と配分順を踏まえて実際に補給できる量を移動先の評価に使います。安全性と輸送中の任務を優先します。
- 20・32盤面と広域戦線32の限定条件で先後を交換し、修正前後を比較しました。守勢の勝敗・補給切れには改善と悪化の両方があり、全マップの公平性や勝率向上を保証する変更ではありません。

## WebKitのCI検証

地形の色比較で、ブラウザーの起動準備をアプリ操作の検証から分離しました。起動時間を記録し、準備失敗も検証失敗として扱います。既存の33回の反復・アプリ側30秒制限・色比較基準は維持します。

ゲーム規則・マップ配置・保存データ／記録済みリプレイ形式・依存ライブラリは変更しません。再開後にCPUが選ぶ行動は変わります。
