# MiniStr v1.4.1

## 変更内容

- 守勢CPUの危険域回避を調整し、拠点へ前進する機会を増やす。地形防御・低HP時の退避・攻撃の安全差は維持。
- 新規の統合戦術マップをTactical v2へ更新。左右の進軍路と中央の補給線を連絡路でつなぎ、水域・施設・初期部隊・作戦目標を保持。
- 32×32の入力ハンドラと、状態・視点・表示条件が同じマスの描画を再利用。フォーカス移動時は対象マスだけの属性を更新。
- 描画再利用を言語・視点・リプレイ・履歴・状態の切替で失効させ、古い表示や入力処理の再利用を防止。

## 比較・適用範囲

未使用seedの32局比較では、改訂マップの守勢対攻勢8局が守勢3→5勝、均衡同士の先後8局が3:5→4:4。元配置の守勢は3勝を維持した。通常規則v12の追加比較でも守勢0→2勝／8局。小標本・相関する往復を含み、全マップの公平性を保証する評価ではない。

ローカル交互3組の32盤面計測では、PCの選択ハンドラp95の中央値78.0→55.9ms、初回選択84.9→76.9ms。390幅の初回選択73.1→67.3ms。390幅の連続選択・初回表示・復帰の一貫した改善は未確認。

旧保存・リプレイは記録済みマップと規則を保持。元カタログ・生成seed・対局／リプレイschema4、キャンペーンschema5は維持。CPUの新しい判断は規則v12以降の今後の手番へ適用される。記録済み指令からの再生結果は保持する。
