## 修正内容

### iPad／iPhoneでのバトルBGM

- 通常曲と戦闘曲を1個の音声要素で切り替え、利用者の操作で再生許可を得た要素を継続して使うようにしました。iOSで別の音声要素の再生が許可されず、戦闘BGMが鳴らなくなる場合への対策です。
- 指を押した瞬間だけでなく、タップ完了後のクリックでも再生許可の取得を試みます。
- 通常曲は曲ごとの再生位置を保持し、音源のメタデータ取得後に復元します。戦闘曲は各バトルシーンの先頭から1回再生します。
- 保留中の再生要求を共有し、古いシーンの再生処理が遅れて完了しても現在の曲を止めないようにしました。再生拒否は次の操作や音源の準備完了時に再試行します。

### 視界外の味方拠点

- 自軍の都市・工場・空港・港・司令部を、ユニットが離れて視界外になった後も所属付きでマップに表示します。
- 拠点の表示と索敵判定は分けています。未索敵の敵ユニットと占領値は、従来どおり非表示／不明です。

## 互換性と既知の制限

- v0.5.0からゲーム規則・セーブ／リプレイ形式・キャンペーン進行・BGM設定の保存形式は変更していません。セーブ／リプレイとキャンペーン進行はschema v4、新規対局は`ruleVersion: 5`を維持します。v0.5.0のデータを引き続き利用できます。
- BGMはブラウザーの自動再生制約に従い、利用者の操作後に再生します。iPad／iPhone実機のEdge・Chrome・Safariでの聴音とタッチ操作は未確認です。ブラウザー自動テストの成功は実機での聴音確認を意味しません。
- 依存パッケージと音楽素材は変更していません。今回、新たな依存監査は実行していません。監査履歴は[依存・配信レビュー](../reviews/2026-10-02-dependency-delivery.md#2026-10-16-再評価pr-163)を参照してください。
- GitHub Pagesは`main`に追随し、タグ固定のプレイ画面ではありません。旧版へ戻す前には必要なセーブをバックアップしてください。
