# v0.4.0 リリースノート

- 対象タグ: `v0.4.0`。タグはリリース準備PRをマージしたコミットに付け、公開Releaseに完全なコミットSHAを記載してください。
- 変更内容の確認対象SHA: `0ba182c5703ff2b66cd7cdbb22ff1e2cff08274d`（PR #190 マージ後の `main`）。準備PRではバージョン表記と本ノートのみを更新します。

## 主な変更

- フィールドBGMを5曲から選べるようにしました（行進・暁・疾走・荒野・霧）。音量設定欄の「BGM曲」で切り替えられ、選択はブラウザに保存されます。戦闘曲は従来どおり固定です。すべて合成したオリジナル音源で、生成スクリプトは `scripts/generate-music.mjs` です。
- 戦闘曲と通常曲を重厚なオーケストラ調に作り直しました。
- 効果音に低域の層を加え、戦闘シーンの砲声・着弾・撃破の胴鳴りを深くしました。
- 戦闘シーンの各ユニットに「赤軍／青軍」のバッジと陣営色の枠・光彩を付け、どちらの軍か分かりやすくしました。
- CPU対戦で「CPUをスキップ」を押すとCPUが止まる不具合への対策を入れました。戦闘演出を閉じたらCPUが次の手へ進む、CPUの1手で例外が出てもターンを安全に終える、CPU行動中でないときのスキップ押下を無視する、の3点です。原因は再現できていないため、再発する場合は報告してください。

## 互換性・既知の制限

- v0.3.0 からゲーム規則・セーブ／リプレイ形式・キャンペーン進行は変更していません（セーブ／リプレイはschema v4、キャンペーン進行はschema v3）。
- BGM設定（`ministr.music.settings`）に `fieldTrack` を追加しました。旧形式の設定は「行進」として読み込み、不正な値は既定に戻します。旧版へ戻しても、旧版は未知の `fieldTrack` を無視して音量・ミュートを読み込みます（フィールド曲は旧版の1曲になります）。
- 音源が増えたため配信サイズが約2.8 MiB増えます。選んだフィールド曲は選択時にだけ読み込みます。
- 新しいBGMと効果音は数値上の確認のみで、聴感の最終確認は未完了です。音声はブラウザーの自動再生制約に従い、ユーザー操作後に再生されます。実際のiOS／Android端末での音声・タッチ操作は未検証です。
- セーブはブラウザーのローカルストレージに保存されます。オフラインでの再起動は保証しません。英語訳と実機アクセシビリティ評価には未完了項目があります。
- 開発依存には GHSA-82fw-gwwq-j7x9 の期限付き例外が残っています。2026-10-16までにVitest 4移行を再評価します。詳細は[依存・配信レビュー](../reviews/2026-10-02-dependency-delivery.md)を参照してください。
- 旧版へ戻す前に、必要なセーブをバックアップしてください。GitHub Pagesは `main` に追随するため、タグの作成だけでは公開画面は切り替わりません。
