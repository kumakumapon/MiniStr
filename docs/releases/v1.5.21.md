# v1.5.21

小型「緑の国境」18×14の3軍版・4軍版を追加しました。各軍4部隊・上限8部隊で、軍ごとの人間／CPU設定、観戦、同端末交代が利用できます。

- 初期選択は小型4軍・人間1軍＋CPU3軍・短期戦。3軍では敵CPU2軍になります。
- 短期戦は全軍の20R終了後、拠点数→合計HPで判定し、首位同点は引分。「決着まで」も選べます。最後の1軍になった場合は即勝利します。
- 実寸に合わせた盤面操作、軍別履歴・undo・自動保存・JSON・リプレイ・同条件再戦に対応します。
- 小型版はengine4・経路2・CPU v5・保存schema5で識別し、全履歴を検証します。
- 既存2軍と広域32×32の対局・規則・CPU版・旧保存を維持します。

20〜30分は試遊目標で、実時間タイマーではありません。物理端末での人間参加時間と開始順／配置の公平性は、測定結果と限界を区別して継続評価します。
