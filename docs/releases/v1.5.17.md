# v1.5.17

固定32×32「四方の前線」で、ユーザーが任意の1軍を操作し、残り3軍を敵CPUとして対戦できるようになりました。従来の全軍CPU観戦も選べます。

- 自軍視界で移動・主/副武器攻撃・占領・生産・待機・合流・搭載・降車・手番終了を操作。対象・攻撃予測を確認し、確定する前に取消できます。
- 敵3軍の処理後は自軍の入力を待ちます。敵手番中とリプレイ中も、生存・未決着なら自軍視界を維持します。停止・背景化・保存・再開時は古いWorker結果を破棄します。
- 担当軍付きの新保存形式を追加。専用2枠、JSON、完全履歴検証、リプレイ、全体バックアップに対応し、旧CPU観戦保存の再開を維持します。
- 自軍脱落後は敗北を表示し、残りの対局を観戦できます。勝利・終局後は命令を止め、保存・再生できます。

既存のゲーム規則・CPU v3・経路規則・固定初期配置・各軍16部隊上限は変更していません。次の4軍残件は、新規未決着20条件・開始順の評価、実時間2/4時間の実機測定、人間参加での難易度・操作性の実戦評価です。

単体1,846件・配布UI67件・関連実ブラウザー108件（Chromium/Firefox/WebKit）を確認しています。
