# v0.9.5 リリースノート

## 主な変更

- タイトルに「今日の戦域」を追加しました。UTC日付から対称マップの条件（サイズ・海域量・戦域設定・seed）を決定的に導き、1操作で作戦準備へ進めます。同じ日なら端末が違っても同じ戦域と戦闘乱数で遊べます。
- 日替わりの対局は、人間の赤軍対CPU・難易度「普通」・有限補給に固定します。対局中は難易度・対戦形式・補給方式を変更できません。出撃前編成を変えた場合は、記録対象外になることを表示します。
- 結果は日付別に、最短ターンと最小損失を別々の最良値としてローカルに記録します。最新60日分を保持し、日付ごとの削除と全体の初期化ができます。識別子（例：`D1-20261025-v3`）を結果画面からコピーできます。
- 日替わりはカスタム作戦（上限32件）に保存しないため、カスタム作戦が満杯でも開始・保存再開・リプレイ・もう一度ができます。
- 日英表示、キーボード操作、スマートフォン幅に対応しました。
- 本体バージョンを0.9.5へ更新しました。

## 互換性と制限

- ゲーム規則v10、セーブ／リプレイ・キャンペーン進行schema4、既存の作戦戦績（`ministr.operations.records`）、対称マップ生成は変更していません。地形・戦闘・CPU・作戦の規則やバランスの変更はありません。
- 記録は新しい保存キー `ministr.daily.records`（独立 schema 1）に保存し、全データのバックアップに含まれます。**このキーを含むバックアップは、v0.9.4以前のバージョンでは復元できません**（「未対応の保存項目」として拒否されます）。旧版のバックアップは新版で復元できます。
- 記録はローカルで編集できる個人用の情報で、認証付きのランキングではありません。
- 日付はUTCで決まります（日本時間では9時に切り替わります）。開始時点の日付で記録します。
- 先後バランスの評価はCPU同士（普通対普通）の152戦の粗い確認で、人間の赤軍とは異なります。極端な偏りは見つからず、18条件すべてを維持しました。
- 保持期間（60日）より古い日付を再開して勝った場合、記録は保存されませんが、通知は「更新しました」のままです。
- 既知の制限：音楽設定（`ministr.music.settings`）が全データの復元で「未対応」として拒否されます。今回の変更で生じたものではありません。
- 実機のスマートフォン、Firefox／WebKit、クリップボードの実機差は個別には確認していません。依存パッケージの更新はありません。既知の監査事項は[Issue #168](https://github.com/kumakumapon/MiniStr/issues/168)で継続管理します。
