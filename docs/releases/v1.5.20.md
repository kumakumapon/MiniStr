# v1.5.20

4軍の開始導線・観測履歴・継続操作

- 人間操作を初期選択にし、CPU進行と記録のリプレイを区別。CPUが先行する参加対局は人間の手番まで進みます。
- 各軍の最終目撃と観測行動を保存し、視界外や敵の準備情報を公開せず、観測された行動を盤上で強調します。
- 単独プレイヤーの同一手番内に最大8命令のundoを追加。戦闘・偵察・新しい視界・CPU進行・読込をまたげません。
- 手動2枠とは別に、人間軍の手番開始の自動保存を追加。不正な既存データの上書きを止め、原本書き出し・独立削除・再試行を提供します。
- 全体終局の軍別集計、記録書き出し、seed・順番・割当・規則・CPU版・設定を引き継ぐ同条件再戦を追加。
- CPUの旧版／現行版、従来／拡張規則を同じ条件で比較する評価スクリプトと、打切りを引分に数えない集計を追加。

schema4の観測参照を全命令履歴から検証します。旧schema1／2／3、旧規則・経路・CPU版、65,536命令・8MB、40MBの全体バックアップを維持します。通常2軍・キャンペーンの戦績には反映しません。
