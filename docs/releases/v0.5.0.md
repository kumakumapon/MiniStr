## 主な変更

### 広域マップと対戦バランス

- 既存の11マップを広域化し、複数の進軍路や橋・港湾を配置しました。通常の対称マップでは初期配置と拠点を180度回転対称にし、後攻の開始資金補償、初回の燃料消費、ラウンド終了時のスコア判定を調整しました。防衛などの非対称作戦は専用の条件を使います。
- 新規の通常戦の判定を40から60ターンへ延長し、期限付きキャンペーンも作戦に応じて延長しました。

### 武器・補給・ユニット情報

- ユニットに武器と弾数上限を設定し、対応施設やAPCで補充できるようにしました。
- 新規対局では兵科ごとに最大2種類の武器を装備します。各武器の威力・射程・残弾を分け、手動選択または有効な武器の自動選択で攻撃します。反撃にも残弾と射程を反映します。
- マップ付近にユニット情報を表示し、武器・残弾・選択を確認しやすくしました。CPU観戦では行動中のユニットの追尾と、指定ユニット付近への移動に対応します。

### キャンペーンとCPU

- 全10作戦を、補給線の確保、突破、防衛、総反攻という連続作戦として見直しました。作戦ごとの目標・期限・補給方針を示し、S/A/B/C評価に応じた次作戦の出撃支援と、生還部隊の経験継承を加えました。
- CPUの占領・保持・上陸・輸送・補給の判断を調整しました。輸送艦や護衛の再建、港湾の生産場所の確保、司令部付近で味方が占領経路を塞ぐ停滞などを修正しました。
- 全作戦の攻略・難易度調整を行い、通常・易しい難易度でのキャンペーン進行を既存の自動検証に含めました。

### バトル演出とBGM

- バトル演出を3.6秒へ拡張し、照準・弾道・着弾・反撃・戦果を順に表示します。武器別の弾道、煙、撃破時の変化を加え、スキップと動きを抑える設定に対応します。
- 戦闘曲は160 BPM・3.5秒で演出内に収まるオリジナル曲へ再作曲しました。01〜04の区切りを持続音とレガートでつなぎ、音量の落差を抑えました。行進以外のフィールド曲も勇壮な編曲へ更新しました。
- BGMの多重再生、曲の終了後に次の戦闘で再生されなくなる判定、再生中の余分な再生要求を修正しました。BGMと効果音の音量設定は個別に利用できます。

### 開発環境

- Vitest本体とcoverageを5.0.2へ揃え、Node/jsdomの`projects`へ設定を移行しました。Node.jsは22.13以降の22系または24系、npmは10〜12が対象です。
- Vitest更新に伴う旧監査例外を解消しました。2026-10-16の更新構成の監査では全依存・本番依存とも指摘0件でした。監査日時と構成は[依存・配信レビュー](../reviews/2026-10-02-dependency-delivery.md#2026-10-16-再評価pr-163)を参照してください。今回新たな依存監査は実行していません。

## 保存互換性と既知の制限

- セーブ／リプレイのコンテナーはschema v4を維持します。新規対局は`ruleVersion: 5`で2武器を有効にし、旧セーブ・リプレイは記録されたルール・マップ定義を使います。v0.4.0などの旧アプリは、未知の新ルールのデータを読み込めません。
- キャンペーン進行はschema v4です。旧schema v1〜v3の解放済み作戦と最高評価を保持して移行し、生還部隊の経験は移行後の勝利から蓄積します。schema v4へ更新した進行は旧アプリでは読み込めないため、旧版へ戻す前に必要なデータをバックアップしてください。
- BGMはブラウザーの自動再生制約に従い、利用者の操作後に再生します。実際のiOS／Android端末での最新BGMの聴感とタッチ操作は未検証です。波形上の改善やブラウザー自動検証の成功を、実機での聴感確認とはしていません。
- セーブはブラウザーのローカルストレージを使います。オフライン再起動、全文英語訳、実機でのアクセシビリティ評価には未完了項目があります。
- GitHub Pagesは`main`に追随します。リリースタグに固定されたプレイ画面ではありません。タグ時点のコードはGitHub Releaseのソースアーカイブを参照してください。
