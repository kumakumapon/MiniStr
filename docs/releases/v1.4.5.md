# v1.4.5

## 大きな盤面の操作応答

- ユニット選択時に盤面とその親要素を取り外さず、ブラウザーが盤面の配置を再利用できるようにしました。
- 表示が変わるタイルもボタンを保持し、属性・内容を更新します。フォーカスの取り直しと不要な再配置を減らします。
- 390幅での初回タップ、スクロール位置、50〜200%の拡大縮小、キーボード操作を確認しました。

同一環境の390幅・32×32比較では、連続選択の処理時間p95が82.5→61.9ms、描画待ち込みで116.1→102.2msになりました。開始・復帰には改善しない条件もあり、全場面の速度向上を保証するものではありません。

## 描画・入力処理の整理

- 画面の更新と盤面フォーカスの処理をUIモジュールへ分離しました。操作ボタンは毎回更新し、イベントの重複や古い状態を残さない構成にしています。
- 言語・盤面サイズ・リプレイの切り替えでは表示を再生成し、霧に隠れた部隊の表示や属性を残さないようにしています。
- ゲーム規則・CPU判断・マップ・保存／リプレイ形式・依存ライブラリは変更しません。
