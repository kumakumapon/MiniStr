# v1.5.3

## ターン表示の整合

タイトル、作戦ブリーフィング、対局中の作戦目標で、実際のシナリオとルール版に基づく時間条件を表示します。緑の国境など8作戦では「制限なし」に代えて「60ラウンド終了時から判定・完全同点なら続行」と案内します。

期限付き作戦は「40ラウンド終了まで」のように最終ラウンドを示します。青軍の内部条件に使う次ラウンド開始の数値と混同しないよう、防衛目標も同じ期限で説明します。本来の生存目標は「第Nラウンド開始まで」、キャンペーンの推奨数は「評価の目安」と明記します。日本語・英語に対応します。

## 互換性

勝敗規則、マップ、CPU判断、補正金、ルールv14、保存・リプレイschema4は維持します。旧保存・リプレイは記録された40／60ラウンド等の判定時期を使います。今回の修正で作戦の期限や難易度を変更することはありません。

確認範囲は[検証記録](https://github.com/kumakumapon/MiniStr/blob/main/docs/reviews/2026-11-08-v1.5.3.md)を参照してください。
