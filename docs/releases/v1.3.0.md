# v1.3.0

守勢CPUの攻撃判断と大盤面の描画・操作応答を改善します。

- 守勢CPUが有利な攻撃を見送る条件を調整。補給合流・砲兵先行・可視情報限定・合法な指令を維持し、未使用seedで先後と方針・難易度を比較しました。
- 盤面の変化のないマスを保持し、変わったマスを更新。日英の翻訳も変化した部分へ適用し、タイトル等の背後にある盤面の計算を削減しました。
- 開発依存minimatchの監査指摘へ対応。jsdomはNode22.13との互換性を維持できる版を保持します。
- 隣接同時攻撃、視界差の奇襲、山・平原・道路の防御補正をまとめて仕様化・比較評価しました。[戦闘ルールの評価](../reviews/2026-10-31-combat-spec.md)に採否と導入条件を記録しています。

## 互換性

ゲーム規則v12、対局・リプレイschema4、キャンペーンschema5を維持。既存の保存・記録済みリプレイを読み込めます。今後のCPU判断は変わりますが、戦闘計算・記録済み指令・先後補償・生成seedは変更しません。

## 検証・制限

最終対象SHA・正式CI・CodeQL・監査・比較条件とrawは[確認記録](../reviews/2026-10-31-v1.3.0.md)とPR #255に記載します。実機iPhone／iPadの確認は低優先度を継続します。比較した条件を超える公平性や、全端末での性能向上を保証するものではありません。

[プレイURL](https://kumakumapon.github.io/MiniStr/)はmainに追随します。正式公開時はRelease本文の相対リンクを公開対象SHAの絶対リンクへ置き換え、main CI・CodeQL・Pagesとタグの一致を確認してください。
