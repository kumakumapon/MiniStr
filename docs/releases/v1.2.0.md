# v1.2.0

32×32の戦域を追加し、広域での操作応答と守勢CPUを改善します。

- 対称マップ生成に32×32を追加。標準／前線補給・工兵、3種類の海域、seed共有、カスタム作戦の保存・再開に対応。
- 単体作戦「広域戦線32」を追加。中央の補給所2か所で20点を目指す支配戦。敵司令部占領・全滅でも勝利し、90ターン終了時に判定します。
- 観戦のズームで盤面を保持し、追従時の重複スクロールを削減。タイトル・作戦準備の裏にある盤面の生成を省き、対局へ戻るときの表示位置を保持。
- 長期リプレイのチェックポイント保持数を盤面サイズに応じて制限。巻き戻し・再生結果・霧の情報境界を維持。
- 守勢CPUが、その場で射撃可能な味方と追撃を連携し、自軍の対応修理施設から有利な反撃を選びます。最大反撃ダメージで撃破される攻撃は追加候補にしません。
- v1.1.0以降にmainへ反映した依存・CI整備、保存一覧／リプレイ最適化、大盤面の選択・通常ズーム改善（#247〜#250）も含みます。

## 互換性

対局ルールv12、対局・リプレイschema4、キャンペーン進行schema5を維持します。既存の保存を読み込めます。CPUの改善は再開後の新しい行動に適用され、過去のリプレイは記録済み指令を再現します。既存サイズのseed・共有リンク・日替わり作戦は生成結果を維持します。32×32の新しい共有リンクはv1.2.0以降で開いてください。

## 検証・公開

対象SHA、性能比較・CPU比較・CIの結果は[評価記録](../reviews/2026-10-29-v1.2.0.md)およびPR #251へ記載します。現時点ではリリース準備中です。

iPhone／iPad等の実機確認は低優先度の未実施事項です。自動ブラウザ検証と実機性能を同一視しません。CPU比較は記録した条件の結果であり、全条件での公平性を保証しません。
