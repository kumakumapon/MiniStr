# v1.4.7

## 表示と操作応答

- タイトルの戦域サムネイルを、画面内と近くのカードから描画します。スクロールすると次のサムネイルを表示し、従来の地形の色・画像を使います。
- 閉じている操作ガイドの兵科比較表を省き、開いたときに生成します。ガイドを開閉するキーボード操作とフォーカスも維持します。

## 戦術を学ぶ単体作戦

- **戦術演習・補給拠点の確保**：10×7。中央の都市を占領し、地上部隊で自軍ターン終了まで3回連続保持します。護衛・生産・実際の補給を試せます。
- **戦術演習・渡河と輸送**：11×8。偵察・架橋・輸送を使い、指定歩兵を出口から撤退させます。迂回して徒歩で進めることもできます。
- 各作戦に6つの任意課題を表示します。占領完了や指定部隊の搭載から降車までを合法な自軍行動から確認し、保存・リプレイ・巻き戻しの履歴と連動します。課題をすべて達成する必要はありません。
- 日本語・英語に対応し、基本操作練習の達成判定も見直しました。

## CPUの限定比較

前回課題が残った32内陸・沿岸、20沿岸の対照、未使用seedの32内陸・沿岸をそれぞれ往復で比較します。修理・補給と行動列も確認し、比較で確認できた範囲を記録します。

既存作戦・キャンペーン・日替わりの定義、戦闘規則、セーブ／リプレイ形式、依存ライブラリは維持します。
