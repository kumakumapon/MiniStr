# v1.4.8

## CPUの回復・目標保持

- 守勢CPUは、保持地点をそのターン中に安全な健康部隊へ引き継げる場合、傷んだ部隊を先に修理へ退避させます。他の保持地点・護衛／撤退対象・搭載中の輸送部隊を交代要員に使いません。
- 占領や、その場からの確実な撃破を担当する部隊を交代へ回さず、優先行動を保ちます。
- 互換性のある自軍施設で、有料修理を安全に続けられる場合はHP50以上まで回復してから前線へ戻ります。攻撃・作戦行動を行ったうえで、通常移動の順番で判断します。新たな交代を決める際は、退避部隊の燃料と公開された期限までの往復見積もりも確認します。
- CPUの判断には自軍情報・公開された作戦指示・視認済みの敵だけを使います。移動中に敵が近づく可能性まで安全を保証するものではありません。

## 初回選択・復帰の応答

- 英語の生成文を上限付きで再利用し、同じ説明の翻訳処理を減らします。再利用中の盤面を属性翻訳の検索範囲から外し、全マスを調べる処理も省きます。日本語／英語とユーザーが入力した名前の扱いを維持します。
- 同じ対局・表示言語の翻訳済み盤面を一時保管し、復帰時の生成・翻訳を減らします。メニュー表示中は操作とCPU更新を止め、別の対局・言語への変更では破棄します。

既存の戦闘規則・マップ・セーブ／リプレイ形式・依存ライブラリは維持します。
