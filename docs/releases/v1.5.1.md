# v1.5.1

## 統合戦術を標準ONに

新しく開始する通常戦・単体作戦では、同時射撃・待伏せ・地形防御・天候予報・地上ZOC・潜航をまとめた「統合戦術」が標準ONになります。対CPU・2人対戦・CPU観戦に適用します。既存のTactical v2地形を使います。

タイトルのチェックを外すと、従来の地形・規則で開始できます。統合戦術ONでは有限補給を使い、OFFでは無制限補給も選べます。ON/OFFの地形差分は別の作戦記録として扱います。

## 適用範囲・互換性

保存済み対局、名前付きスロット、進行中の対局、リプレイは、記録された地形・規則・乱数を保持します。キャンペーン・日替わり・基本訓練は専用の設定を使います。ルールv14・セーブ／リプレイschema4を維持します。

全26作戦の攻略条件とCPU動作、限定条件での先後比較を確認しました。小規模な比較で全作戦の公平性や人間同士の勝率を保証するものではありません。詳細は[確認記録](../reviews/2026-11-07-v1.5.1.md)を参照してください。
