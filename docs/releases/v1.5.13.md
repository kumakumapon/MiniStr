# v1.5.13

## 4軍の開始メニュー・観戦画面

タイトルから4軍CPU観戦を開始できます。専用32×32「四方の前線」で、seed・手番順・軍別CPUの難易度/方針を選び、再生/停止・1手送り・速度・全体/軍別視点・拡大縮小・部隊への移動を操作できます。PC/スマートフォン、日本語/英語に対応します。

名前付き専用保存2枠、JSON書き出し/再開、リプレイの位置移動、全データバックアップへの同梱/復元を追加しました。読込時に固定初期条件と命令履歴を検証します。通常対局・研究保存・成績と分離しています。

設定変更・背景化・画面切替では進行とWorkerを取り消します。100ラウンドごとの停止は明示的に再開できます。初版の記録は2,048命令/1MBまでで、上限では保存・書き出しを残して進行を停止します。

次の4陣営対応は、公平性・長期性能の最終判定と、長期記録/保存の拡張です。最大4陣営全体の完了判定は継続します。
