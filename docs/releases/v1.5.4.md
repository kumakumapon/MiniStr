# v1.5.4

## 護衛任務の出口混雑

統合戦術ON・ルールv14の護衛対象の補給車について、味方の閉塞で出口へ近づけない場合、同じ手番で届く出口までの経路を調べ、安全に退避できる味方を先に動かします。連鎖した閉塞も空いている側から調べ、移動のたびに現在の盤面から判断し直します。

既に前進できる場面では従来の護衛判断を使います。行動済み部隊、別の任務対象、施設や保持目標上の部隊、搭載部隊を持つ輸送役は退避対象にしません。退避先は観測済みの敵の移動・攻撃を考慮し、味方を犠牲にする移動を強制しません。

## 適用範囲と互換性

撤退任務の既存判断、戦闘・勝敗規則、マップ、先後補償、ルールv14、対局保存・リプレイschema4、campaign schema5は維持します。旧規則と統合戦術OFFは対象外です。保存済みv14対局を再開した後のCPU命令は改善後の判断になります。記録済みリプレイは保存された命令を再現します。

既知の出口混雑条件はT61期限敗北からT23達成へ改善しました。すべてのseedや難易度での作戦達成を保証する変更ではなく、別seedで残る護衛失敗も記録しています。新兵科・新作戦・4陣営は含みません。

検証した条件・命令履歴・未確認事項は[検証記録](https://github.com/kumakumapon/MiniStr/blob/main/docs/reviews/2026-11-10-v1.5.4.md)を参照してください。
