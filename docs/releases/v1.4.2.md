# MiniStr v1.4.2

## 変更内容

- CPU観戦は戦闘・占領・補給の演出中にも「観戦を一時停止」を操作できる。演出を終了して盤面へ戻り、明示的に再開するまでCPU命令を進めない。
- 演出中の「停止して観戦メニュー」から観戦の終了・タイトルへ戻る操作へ進める。盤面へ戻っても停止を維持する。
- 予約された次命令・遅いCPU応答を停止後に適用せず、確定済みの戦闘結果・弾薬・乱数・履歴を保持する。演出スキップと通常対局・リプレイの操作は維持。
- 保存できるタブを1つに限定し、同時書き込みからセーブ・進行・設定・バックアップ復元を保護する。別タブでは保存不可を案内し、現在の対局の書き出しと再試行を用意する。
- 書き込み権を取り直しても、別タブで変更された古い内容を上書きしない。既存の競合検知・破損原本出力・正常対局救出・旧保存の読み込みを保持する。

## 利用上の注意

保存できないタブでは、保存可能なタブの進行を保存・書き出ししてから、そのタブを閉じて「保存を再試行」を選ぶ。別タブでデータが変わっていた場合は、現在の対局を書き出してから再読み込みする。安全な保存に対応しない環境では永続保存を拒否し、書き出しを利用する。ブラウザの保存領域自体を使えない場合は従来のメモリ保存となる。

同時書き込みの排他はv1.4.2の同じ方式を使うタブ間が対象。更新前から開いている旧版タブは閉じてから利用する。既存の保存形式・ゲーム規則・CPU判断・マップは変更していない。
