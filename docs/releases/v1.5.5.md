# v1.5.5

## 護衛対象の修理完了

統合戦術ON・ルールv14で、損傷した護衛対象の地上補給車が、自軍の修理拠点から早く出てしまうCPU判断を修正しました。守勢以外の方針でも、HP50未満・修理費用あり・搭載なしの場合に既存の修理待ちを使います。観測済みの敵の射撃で撃破されると見積もる場所では待機を強制せず、出口にいる対象は脱出を優先します。

既知のseed15422・赤hard/青easyでは、HP35で出発してT16に護衛対象を失っていたところを、もう1回修理してT18に達成します。既知の出口混雑修正も維持します。

## 適用範囲と互換性

撤退任務、旧規則、統合戦術OFF、戦闘・勝敗規則、マップ、UI、依存版、CI公開条件は変更していません。ルールv14、対局保存・リプレイschema4、campaign schema5を維持します。保存済み対局の再開後のCPU判断は変わり得ますが、記録済みリプレイは保存された命令を再現します。

148条件の比較で従来勝利の敗北化はなく、147条件の全命令が一致しました。全seed・全難易度での達成を保証する変更ではありません。
