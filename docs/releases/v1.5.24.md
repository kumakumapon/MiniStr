# v1.5.24

4軍の対局・CPU観戦・リプレイで、占領・補給・修理の演出を表示するようにしました。

- 占領の進捗・完了と実際の軍名・色、補給・修理による耐久・燃料・主／副武器弾薬の増加を表示します。
- 「占領・補給演出を表示」でON／OFFを切り替えられます。2軍と複数軍（2〜4軍）で別々に保存し、バトルシーンの設定とも独立しています。初期値は表示です。
- 2軍はタイトル・対局画面、複数軍は開始条件・対局画面から変更できます。演出内でチェックを外すと、その演出を閉じて以後の占領・補給・修理演出を省略します。
- CPU・自動再生は演出が終わるまで待機します。スキップ、一時停止、開始条件へ戻る、画面離脱にも対応します。
- 未索敵の占領や敵軍の補給情報は表示しません。端末交代では次の人の操作開始まで補給演出を待ちます。

対局の保存形式・規則・CPU版を維持します。演出OFFでもゲーム結果と命令履歴は同じです。表示設定は再読込・全体バックアップでも保持します。新設定を含むバックアップの復元にはv1.5.24以降を使ってください。
