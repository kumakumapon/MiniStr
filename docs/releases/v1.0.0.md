# v1.0.0 リリースノート

## 主な変更

- フィールドBGMのループ継ぎ目を解消しました。ブラウザーの `<audio loop>` はループ境界に約6msの無音が入る（Chromiumで実測）ため、Web Audio のバッファループで再生します。戦闘曲も同じ方式です。Web Audio が使えない、またはデコードできない環境では従来の `<audio>` 再生に切り替わり、無音にはなりません（#241）。
- 生成マップの条件（生成版・サイズ・海域量・戦域設定・seed）を、共有リンク（URLハッシュ）で友人に渡せるようになりました。ジェネレーターの「共有リンクをコピー」で作り、リンクを開くと確認画面で条件を確かめてから作戦準備へ進みます。確認前には何も保存せず、既存の保存データは上書きしません。不正・巨大・未知の版のリンクは理由を表示して拒否します（#231、#243）。
- タイトル画面の状態・表示データの組み立て・イベント処理を `main.ts` から `src/ui/` へ分割しました。見た目と操作は変えていません（#233、#242）。

## 互換性と制限

- ゲーム規則v11、セーブ／リプレイ・キャンペーン進行schema 4、localStorageの保存キーとバックアップ形式は変更していません。旧データはそのまま読み込めます。共有リンクは新しい保存キーを追加せず、確定した時だけ既存のカスタム作戦（上限32件）に追加保存します。
- 共有リンクの対象は生成マップの条件だけです。カスタム作戦のJSONは対象外で、従来のJSONファイル共有を使います。日替わりチャレンジと同じ形式のseed（`D` と8桁の数字）は共有リンクにできません。生成ロジックは変更しておらず、将来生成が変わっても旧リンクが同じ戦域を再現するよう、リンクに生成版を含めています。
- iOSのサイレントスイッチがオンの場合、Web Audio 再生のBGMが鳴らない可能性があります（`<audio>` 再生は鳴ります。効果音は従来から Web Audio です）。
- 当初の計画（`docs/plans/v1.0.0.md`）にあった次の項目は、このリリースでは実施していません。1.x系で実施します。
  - ルールv12（広域偵察、橋の破壊、軍方針、継続部隊・分岐キャンペーン）: [#244](https://github.com/kumakumapon/MiniStr/issues/244)
  - 互換性の約束の文書化、現状の公開前確認の記録、`npm audit` の確認と対応: [#245](https://github.com/kumakumapon/MiniStr/issues/245)。既知の監査事項は[Issue #168](https://github.com/kumakumapon/MiniStr/issues/168)と[#155](https://github.com/kumakumapon/MiniStr/issues/155)で継続管理します。
- 次の項目は実機で確認していません: iPhone/iPad（Safari）でのBGM再生・クリップボード・タッチ操作、スクリーンリーダー、Safari/iOS での Ogg Vorbis のデコード、WebKit でのループ継ぎ目。Firefox/WebKit はe2eの範囲でのみ確認しています。依存パッケージの更新はありません。
