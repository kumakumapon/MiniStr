# v1.6.1

複数軍の画面で、よく使う操作を見つけやすくし、地形と敵の脅威を確認できるようにしました。

- スマホの操作バーでは、人間の手番は「ターン終了」、CPUの手番は「CPU進行」または「一時停止」を赤で強調します。
- 開始条件・対局の「BGM設定」でオン／オフ・音量・共通曲・第1〜4軍の曲を選べます。軍別設定では表示中の手番に合わせて切り替わります。複数軍BGM設定を含む全体バックアップの復元にはv1.6.1以降が必要です。
- タイトル画面で選んだCPU速度と盤面倍率を、新しく始める複数軍対局へ適用します。「自動」は実際の盤面サイズと画面幅で決まります。保存からの再開では保存済みの速度を使います。
- 盤面下の地形・施設の凡例と「マス情報」で、防御効果と、部隊を選んだときの移動コストを確認できます。
- 「敵の脅威範囲」で、現在の軍から見えている敵の移動・射程の目安を表示します。自軍部隊を選択しているときは、その兵科を狙える武器が対象です。
