# v1.1.0 リリースノート

- 工兵で隣接する空き仮設橋を破壊できるようになりました。確認操作、CPU、保存・取り消し・リプレイに対応します。
- CPUの軍方針に「均衡・攻勢・守勢」を追加しました。出撃前に選択でき、観戦では両軍を別々に設定できます。難易度とは独立し、保存・再開でも引き継ぎます。
- キャンペーンに選択できる経路を追加し、生還部隊のコールサインと経験を次の編成へ引き継げるようにしました。作戦一覧から部隊名を編集できます。短縮経路には追加の出撃支援があります。
- 1.xの互換性方針と公開前確認記録を整備し、開発・テスト用依存の監査対応を行いました。

新規対局はルールv12。対局・リプレイはschema4を維持し、旧形式・旧ルールの対局を読み込めます。キャンペーン進行はschema5となり、schema1〜4を移行できます。旧アプリではv12対局とschema5進行を開けません。

今回のCPU評価は人間同士の公平性や、どの軍方針が常に強いかを保証するものではありません。実機iPhone/iPadの操作・出音・読み上げは未確認です。
