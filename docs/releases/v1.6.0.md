# v1.6.0

READMEを開いてすぐに、MiniStrがどんなゲームか、どこで遊べるか、各モードをどう始めるかが分かるようになりました。公開ページへのリンクをタイトルの直下に置いています。

- 通常の2軍対局、キャンペーン、小型・広域の3／4軍対局、CPU観戦の始め方をまとめました。
- 版ごとの説明を変更履歴へ移し、各版のリリースノートや評価記録へのリンクを引き継ぎました。
- 開発向けのモジュール案内を実装ガイドにまとめ、複数軍・CPU Worker・保存検証の入口を追加しました。

変更対象はドキュメントと配布版の表示番号です。 [ブラウザーで遊ぶ](https://kumakumapon.github.io/MiniStr/)・[対応Issue #319](https://github.com/kumakumapon/MiniStr/issues/319)
