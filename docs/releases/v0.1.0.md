# v0.1.0 リリースノート（訂正版）

対象タグ: `v0.1.0`。対象SHA: `b9cde2f9a67536c4ab2c8f30004eb0a982800e33`。

MiniStrの初回リリースです。

- **10ステージ**のキャンペーン
- CPU対戦、ホットシート対戦、CPU同士の観戦、リプレイ入出力
- 地形プレビュー付きタイトル画面とマップエディタ
- 手動・自動・名前付きの複数セーブスロット、localStorage使用量表示
- GitHub Pagesによるブラウザー配信

このタグにはunit/UIテスト、カバレッジ基準、CPU対CPU回帰、Playwright E2E、lint・format・型チェックが既にあります。追加の境界ケース、配布成果物そのものの確認、複数ブラウザー検証は継続改善の対象です。「テスト基盤全体が未実装」という意味ではありません。

既知の制限: 日本語中心のUI、カスタム定義の差し替えと旧セーブの互換性、保存失敗・破損時の回復導線、main.tsの責務分割には改善余地があります。#155 / #156での新しいschema-4保護、バックアップ、練習マップ等はこのタグの機能に含めません。

公開プレイURL: https://kumakumapon.github.io/MiniStr/ 。このデモは **main追随** で、v0.1.0に固定された配布版ではありません。タグのコードはGitHub Releasesのソースアーカイブを参照してください。
