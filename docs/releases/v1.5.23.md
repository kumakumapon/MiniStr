# v1.5.23

4軍の対局・CPU観戦・リプレイでも、2軍と共通のバトルシーンを表示するようにしました。

- 攻撃側・防衛側の実際の軍名、兵種、使用武器、戦闘前後のHP、反撃・同時射撃・待伏せ・撃破を表示します。
- 2軍と複数軍（2〜4軍）で、バトルシーンの表示／非表示を別々に設定できます。初期値はどちらも表示です。2軍はタイトル・対局画面、複数軍は開始条件・対局画面から変更できます。
- 演出内のチェックを外すと、その演出を閉じて以後の戦闘演出を省略します。設定は再読込・バックアップ／復元でも引き継ぎます。
- 4軍のCPU進行は表示中の演出が終わるまで待機し、スキップ・一時停止・開始条件へ戻る・画面離脱で演出と効果音を解除します。
- 未索敵の戦闘や端末交代中の情報は表示しません。非表示でも盤面上の行動表示・戦闘結果・保存内容は維持します。

対局の保存形式、戦闘規則、CPU版は変更しません。2軍の占領・補給・修理演出は、今回の戦闘演出設定とは別に従来どおり表示します。
