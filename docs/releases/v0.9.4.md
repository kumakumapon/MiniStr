# v0.9.4 リリースノート

## 主な変更

- タイトルの戦域サムネイルと実際の盤面で、同じ地形画像とテーマ処理を使用するようにしました。砂漠・雪原などで色味が食い違う表示を修正します。森・山・道路の画像参照列も修正しました。部隊と所有者の赤青は維持します。
- 赤軍／青軍の手番でBGMが切り替わります。両軍の曲を選択でき、従来の共通曲方式にも戻せます。観戦・保存再開・リプレイにも適用します。
- オリジナルのロック調BGM「烈火（160 BPM・24秒）」「蒼雷（148 BPM・約25.95秒）」を追加しました。既存の曲も選べます。
- タイトルからBGMのオン／オフ、音量、陣営別の曲を設定・試聴できます。対局中の設定と同期して保存します。
- Issue #213の新案として、盤面近くへテーマ対応の「地形・施設の凡例」を折り畳み表示で追加しました。
- 本体バージョンを0.9.4へ更新しました。

## 互換性と制限

- ゲーム規則v10、セーブ／リプレイ・キャンペーン進行schema4を維持します。地形・戦闘・CPU・作戦の規則やバランスの変更はありません。
- 旧BGM設定の音量・ミュート・選択曲は維持し、新しい陣営別項目を補います。切り替え方式は設定で変更できます。
- 戦闘専用BGMと単一音声要素による再生は維持します。実機iPhone／iPadでの操作・出音は今回未確認です。
- 依存パッケージの更新はありません。既知の監査事項は[Issue #168](https://github.com/kumakumapon/MiniStr/issues/168)で継続管理します。新曲は外部録音を使わないオリジナル音源でMITライセンスです。
