- v0.7.0から、広域偵察・拠点支配戦・単体作戦の戦績と、生成マップの評価・再現性を拡張する機能更新です。

## 主な変更

### 回数制限付き広域偵察

- 新規対局では各軍が1作戦につき2回、指定マスから半径3を自軍のその手番中だけ視認できます。手番終了時に一時視界が消え、残回数は保持します。
- 盤面付近から地点を指定し、中止・Esc・取り消し・保存再開・リプレイに対応します。確認した敵は既存の索敵記録へつながり、視界外では最終確認と現在の位置を区別します。
- CPUも同じ回数と視認規則で使い、地点選択は味方・地形・公開目標から行います。未索敵の敵位置や弾薬・燃料を選択根拠にしません。

### 拠点支配戦と単体作戦2本

- **十字路の支配戦**・**沿岸拠点の争奪**を追加し、単体作戦は計7本になります。通常11マップとキャンペーン10作戦の定義は維持します。
- 指定都市を所有すると、両軍の手番が終わったラウンド終了時に各都市1点を同時加点します。常駐部隊は不要で、12点に到達すると勝利。同時到達では高得点側が勝ち、同点は継続します。
- 対象都市の所有と両軍の得点は公開情報として盤面付近に表示します。隠れた敵部隊は表示しません。CPUの確保・奪還判断、エディタ、保存・リプレイ、勝因表示にも対応します。

### 戦績・追加チャレンジ

- 人間の赤軍対CPUによる組み込み単体作戦の勝利を、作戦版・ルール・難易度・初期編成と開始資金の条件ごとに記録します。
- 最短ターン・最小損失と、規定ターン以内・味方損失2以下・初期部隊全員生存の達成を保存します。追加課題は勝利とは別で、能力や資金の強化報酬はありません。
- 結果画面とタイトルの折り畳み一覧で確認し、編成条件の表示と個別削除ができます。同じ勝利の再表示・再読込で重複加算しません。観戦・リプレイ・2人対戦・キャンペーン・カスタム作戦は対象外です。
- 最大128条件・384,000バイトで検証し、破損・容量不足・上限到達は通知して既存記録を保持します。全データのバックアップと復元にも含めます。

### 生成マップv2とCPU・表示の改善

- 地形・兵力・青軍の開始補償2000Gを維持し、生成条件ごとに戦闘乱数の開始値を分けます。同じ生成条件から同じ対局を再現でき、保存済みのv1定義は従来の地形・資金・戦闘seedを維持します。
- 生成seedと戦闘seed、サイズ、海域、配置方向、難易度、版を固定して比較するコマンドを追加しました。時間・命令上限、途中失敗、各対局と集計をJSONLで記録できます。
- 新ルールでは、偵察後に撤退対象が停滞する問題を修正し、脱出への前進と味方の通路塞ぎ解消を優先します。
- 偵察・支配欄を部隊情報の上に配置し、部隊情報はマップに隣接させます。PC・スマートフォンとも、既存の12px以内という距離検査を維持しています。

## 保存互換性と既知の制限

- 新規対局は`ruleVersion: 7`です。旧対局は記録されたルールを維持し、旧ルールの視認・撤退判断を変更しません。セーブ／リプレイとキャンペーン進行のschema v4も維持します。
- 戦績は独立したschema v1のローカル保存です。v0.7.0以前のアプリはルールv7の対局を読み込めません。旧版へ戻す前に必要なデータを全データバックアップへ書き出してください。ローカルの個人記録であり、認証されたランキングではありません。
- **生成マップの先後バランスは条件によって偏りが残ります。** 同難易度・全3サイズと全3海域・配置回転を含む216対局はv1赤61勝／青47勝、v2赤60勝／青48勝。16マス幅・沿岸では改善しましたが、20・24マス幅などには悪化した条件もあります。難易度交換の別seed8対局は赤7勝／青1勝です。
- 回転対局など対応のある条件を含み、216個の独立標本ではありません。全seed・全難易度・人間同士の公平性を確認したものではなく、追加評価は[Issue #213](https://github.com/kumakumapon/MiniStr/issues/213)で継続します。道路拡幅と補償1000Gは別seedで悪化し不採用です。詳細は[比較結果・再現コマンド・全対局データ](../reviews/2026-10-19-generated-balance.md)を参照してください。
- PC1280×800とスマートフォン幅390×844で新機能の操作を自動検証し、画面8枚を確認しました。iPhone／iPadなどの実機でのタッチ操作は未確認です。ブラウザ検証はChromiumの主要導線とFirefox・WebKitの互換性確認を含みます。音声はブラウザーの自動再生制約に従います。
- 依存パッケージと音楽素材は更新していません。上記ゲーム内容の対象SHAに対するCIの`npm ci`は2026-10-20に`0 vulnerabilities`を報告しました。独立した新規`npm audit`コマンドは実行していません。過去の監査履歴は[依存・配信レビュー](../reviews/2026-10-02-dependency-delivery.md#2026-10-16-再評価pr-163)を参照してください。
- GitHub Pagesは`main`に追随し、タグ固定のプレイ画面ではありません。タグ時点のコードはGitHub Releaseのソースアーカイブを参照してください。
