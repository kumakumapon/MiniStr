# v1.5.18 — 4軍UI・操作を2軍に統一

4軍対局を、通常の2軍対局と同じ盤面・部隊画像・情報カードで操作できるようにしました。

- 部隊を選択して移動先・敵を押す直接操作。移動後の選択維持、主／副武器と自動選択、視認した敵の予測・脅威範囲。
- 待機・占領と輸送操作、施設からの生産メニュー、未行動部隊一覧・Nキー、スマートフォンの常設クイック操作。
- 初期44pxの盤面と共通ズーム。矢印／Home／End、Enter／Space、Escで操作し、更新中も盤面ボタンを保持。

固定32盤面・全軍敵対・ユーザー1軍・敵CPU3軍、自軍視界、CPU判断、保存schemaと旧データ、リプレイの読取専用を維持しています。通常の2軍画面には4軍専用のスタイルを適用しません。公開済みv1.5.17は保持します。

[仕様](../four-army-ui-parity.md)。検証結果は公開前にレビュー記録へ追記します。

3. 人間参加の実戦評価による難易度・操作性の調整（今回の操作統一を含む）。
