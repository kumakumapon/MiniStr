# v0.9.3 リリースノート

## 主な変更

- タイトル画面からカスタムマップを削除できます。マップ名付き確認、中止、失敗時の通知、日本語・英語とタッチ操作に対応します。組み込みマップは削除できません。
- マップを一覧から削除しても、進行中の対局と保存・リプレイは保持します。エディタの削除も同じ確認を使います。
- 新規対局に補給車の物資上限を導入しました。APC1両300ポイント、弾薬1発10、燃料1につき1を消費し、残量不足では部分補給します。自軍施設・前線補給所で補充できます。
- CPUが物資残量と補充先を考慮し、空の車両を補給源にしないようにしました。自軍の残量、部分補給の見通し、空車を除く補給範囲を表示します。敵の残量は非公開です。
- キャンペーン以外の作戦準備では有限補給／従来の無制限を選べます。本体バージョンを0.9.3へ更新しました。

## 互換性と制限

- 新規の有限補給はルールv10、無制限はv9です。既存の対局・リプレイは記録された規則を維持し、途中で有限へ変更しません。
- セーブ／リプレイ・キャンペーン進行はschema v4を維持します。旧保存は継続できますが、**v0.9.2以前のアプリではルールv10の保存を開けません**。新しいキャンペーン出撃はv10です。
- 依存パッケージ・音楽素材の更新はありません。依存監査の既知事項は[Issue #168](https://github.com/kumakumapon/MiniStr/issues/168)で継続管理します。
- 42対局のCPU比較と通常キャンペーン全10作戦を確認しました。小標本の機械評価であり、全生成条件の公平性や人間の難易度を保証しません。
- 実機iPhone／iPadでの操作は未確認です。ブラウザのスマートフォン幅による確認とは区別します。
