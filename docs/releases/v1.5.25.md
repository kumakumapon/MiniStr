# v1.5.25

複数軍の長期対局で、消耗した占領部隊の補充、修理・弾薬回復、砲兵の間合い、輸送艦の移動後の上陸、橋の必要性と終盤の司令部攻略を改善しました。新規対局はCPU v7を使用します。

- 旧版で400Rまで未決着だった6条件は、改善版では4条件が326R、2条件が379Rで決着しました。
- 新しい3軍の陸上配置では、北側の中立工場と都市だけを1マス内側へ移しました。初期司令部・部隊・資金は同じです。未使用seedによる比較では戦術OFFの北側が改善しましたが、戦術ONの偏りは残ります。
- 水域・固定チーム戦の長期保存、全履歴検証、再開後の命令・状態・乱数、再生の取消とキャッシュ上限を検証しました。実CPU12条件で最大8,192命令、保存負荷4条件で300Rまで確認しています。水域3軍2条件と広域チーム2条件は検証上限で未決着です。
- 途中参加・潜水艦・動的同盟について、保存互換と受入条件を含む[後続仕様](../multifaction-v3-design.md)を確定しました。実対局への追加は後続版で行います。

通常2軍の規則・CPU・保存を維持します。過去の複数軍保存は元のCPU・配置で継続し、改善版CPUは明示的に切り替えられます。切替で過去の履歴や配置は置き換えません。CPU v7／配置v3を含む保存にはv1.5.25以降が必要です。
