# v1.4.4

## CPU・兵站

- 補給車の物資を実際の補給順で見積もり、先に別の部隊へ配る分を考慮します。届かない物資を前提に弾切れ部隊を待機させることを防ぎます。
- 補給車の移動後も合流地点の安全評価を確認し、危険と判断した地点で補給待ちを固定しません。
- 守勢CPUは、弾薬・燃料が残っていてもHP50以下なら修理可能な自軍施設を評価します。自軍資金・収入に応じた回復量を使い、補給車・補給所をHP修理施設とは扱いません。

## 比較・互換性

- 広域戦線32と生成マップを先後交換し、軍方針・難易度・陸海・戦闘乱数・後攻補償を変えて比較しました。修理・補給の実測指標と難易度／補償の指定を比較ツールに追加しました。
- 最終の生成16局では守勢9→8勝、広域16局では4→5勝。勝率の全般的な向上は確認していません。修理回復量や物資不足の結果も条件別に公開します。
- 比較したマップ変更案には悪化条件があり、現行配置を維持しました。戦闘規則・既存マップ・生成seed・保存／リプレイ形式は変更しません。記録済み指令の再生は維持し、新しいCPUの判断は変わります。
