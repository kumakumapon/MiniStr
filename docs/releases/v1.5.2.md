# v1.5.2

## CPUの護衛・撤退

統合戦術ON・有限補給のCPUが、護衛・撤退任務の補給車を守る判断を改善しました。撤退では脱出地点に近い必要数の対象を優先します。前方へ突破する場合は護衛を先に動かし、自軍首都に近づく後方撤退では対象を先行させます。確認済みの敵による移動後の攻撃、地形・天候・ZOC・武器の移動後制限を考慮し、危険が大きく増える前進を抑えます。

脱出地点へ今すぐ到達できる場合は撤退を優先します。近くの護衛が支援できる場合や、致命的な危険がなく次の移動で脱出できる場合は前進します。戦闘部隊、海空輸送、統合戦術OFFや旧ルールの判断は今回の対象外です。

調整用32条件の任務達成は15→26、最終未使用seedの32条件では19→27でした。護衛1条件は自軍が出口手前に密集して待機が長引き、勝利から期限判定の敗北へ変わりました。残る護衛の未達と出口の混雑解消を継続課題とします。

## 依存整備・互換性

ESLintを10.14.0、Vitest本体・coverage-v8を5.1.0へ同時更新しました。依存だけのCIを先に確認してからCPUを変更しています。

ルールv14、保存／リプレイschema4、戦闘規則、原典マップ、Tactical v2地形、先後補正金は維持します。保存済み対局は記録された規則を使い、再開後の新しいCPU判断には改善が適用されます。既存リプレイの記録済み命令は変更しません。

比較条件・悪化条件・検証範囲は[確認記録](../reviews/2026-11-07-v1.5.2.md)を参照してください。
