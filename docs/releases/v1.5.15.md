# v1.5.15

## 4軍CPUの停滞・方向差を限定修正

視界外の自軍工場への生産が拒否され、未行動部隊まで手番を失っていた原因を修正しました。部隊の行動を先に終え、視界外での正当な生産と隠れた敵情報の保護を維持します。同点候補の絞り込み・最終選択は自軍司令部から見た座標に統一し、絶対座標や部隊IDによる方向差を取り除きました。

新規対局はCPU v2。旧保存は旧CPUを維持して読み込めます。「改善版CPUへ切り替え」で、現在局面・命令履歴・元の保存を保持して続きの判断を変更できます。65,536命令/8MB、ゲーム規則・初期条件・2軍CPUは維持しています。

固定候補の201回比較を完了しました。既存の同設定72条件は50決着/22未決着→64決着/8未決着、第3軍の勝利は6→14件。別seed・全24手番順の48条件は34決着/14未決着→43決着/5未決着でした。新版144条件で、未行動部隊を残す視界外生産/生産拒否は0回です。

旧版で決着した条件が新版では未決着になる例も9条件あり、全体の公平性や全対局の決着を保証する結果ではありません。残る移動経路・未知敵接触の回転差は、旧命令再生に影響する規則改修として分けました。次の残件はこの規則と保存互換、残る未決着の個別診断、実機・2/4時間の継続測定です。
