# v1.5.15

## 4軍CPUの停滞・方向差を限定修正

視界外の自軍工場への生産が拒否され、未行動部隊まで手番を失っていた原因を修正しました。部隊の行動を先に終え、視界外での正当な生産と隠れた敵情報の保護を維持します。同点候補の絞り込み・最終選択は自軍司令部から見た座標に統一し、絶対座標や部隊IDによる方向差を取り除きました。

新規対局はCPU v2。旧保存は旧CPUを維持して読み込めます。「改善版CPUへ切り替え」で、現在局面・命令履歴・元の保存を保持して続きの判断を変更できます。65,536命令/8MB、ゲーム規則・初期条件・2軍CPUは維持しています。
