# 4軍実対局エンジン（v1.5.10）

v1.5.9の[確定仕様](four-army-foundation.md)の次段階として、4軍専用state・行為軍付き命令・戦闘と手番の状態遷移・JSONチェックポイントを実装した。小盤面で実際に命令を適用して検証する基盤であり、アプリの4軍CPU観戦画面・専用32盤面はまだ提供しない。

## エンジンの範囲

- `createFourArmyState(map)`で不変のマップsnapshot（4司令部、初期部隊/資金、手番順、seed）から開始する。最初の軍を含め、各軍の開始時に収入・補給・有償修理を適用する。全軍の初回維持燃料は免除する。
- `applyFourArmyCommand(state, command)`は`actor: army1〜army4`を必須にし、行動軍・合法性を検証する。命令はmove / attack / capture / produce / wait / merge / embark / disembark / endTurn / resume。失敗は元stateを維持する。
- `engineVersion: 1`は従来v12相当の移動・主副武器/弾薬・反撃/乱数・経験・生産・有限補給・修理・輸送を使う。既存2軍のPlayerId/GameState、規則版、セーブ・リプレイは変更しない。
- 既存ルールを呼ぶ間だけ、行動軍とそれ以外を区別した一時盤面を作る。部隊ID・施設位置から元の4軍所有者へ戻し、他軍の資金を更新しない。この一時盤面を4軍の保存やCPU入力へ渡さず、2軍の勝敗・スコア・endTurnを採用しない。
- 各命令後と燃料死後に、同じsnapshotから全軍の脱落を判定する。脱落した部隊/cargoを除き施設を中立化し、占領した生存軍の司令部所有は維持する。最後の軍で終局し、その後の命令を拒否する。
- 固定4枠のカーソルで脱落軍を飛ばす。現在軍の燃料死も同じ状態遷移内で解決し、ラウンド境界と次軍の開始を各1回だけ処理する。100ラウンドごとに、境界処理済み・次軍開始前のpendingで停止する。resume時だけ次の開始を適用する。
- `observeFourArmy(state, army)`は自軍部隊と可視の敵部隊、公開盤面、自軍資金を返す。隠れた敵・敵cargo/兵站・敵資金・乱数状態を返さず、他軍の視界を合算しない。返却値の編集で原本を変更できない。
- 生産はfactory/airport/portを分離したfacility-v2。試作の計算境界は2〜32マス各辺・総128部隊、従来の盤面別生産制限も適用する。これは初版公開の部隊上限・公平性の確定値ではない。
- 橋・築城・偵察命令、v13/v14の戦術ON・潜航・天候・兵站指示は、このengineVersionでは有効化しない。追加時は互換性と軍別の期限処理を検証して版を更新する。同時射撃の実戦闘は未接続で、同時脱落判定自体はv1.5.9の参照モデルを再利用する。

## 検証付きチェックポイント

`serializeFourArmyArchive(map, commands, state)`と`parseFourArmyArchive(text)`は、予約済みの`ministr-four-army-save` / schema1 / `four-army-v1`を使う。payloadは元マップsnapshot・行為軍付き命令履歴・現在state。初期状態を作り直し全命令を再生して、乱数・手番・資金・脱落履歴を含めて一致した場合だけ読込成功とする。開始済みactiveの読込は収入・補給を再実行しない。

1MB・2048命令・構造深さ/項目数の境界、厳密なキー/値域、同軍の実在する輸送参照、未知版、改ざん・不一致を検証する。これはエンジン検証用codecで、名前付きスロットやlocalStorageへ書き込むUIではない。既存2軍/研究/復旧の読込はこの形式を拒否する。保存キーやバックアップ登録を追加しない。

元マップは入力されたsnapshotとして検証する。正式32盤面のID/配置/CPU設定は未採用であり、このcodecを既存作戦の正規セーブとして読み込まない。公開向けリプレイ形式・長い命令列・軍別CPU設定の永続化は次段階で設計/接続する。

## 検証と次の残件

新規テストは全24手番順、3敵軍への攻撃、合法/不正命令と不変性、敵視界の分離、移動時の隠れた接敵、搭載/輸送損失、司令部占領/脱落、燃料死と現在軍の脱落、有限補給/修理/生産、最終勝利、100ラウンド停止/再開、JSON再現・旧読込拒否を対象にする。

次は複数敵CPUとWorker取消・軍別の可視情報を使う判断への接続。続いて専用32盤面の配置/資金/部隊上限を比較し、軍別HUD/視点/難易度/方針・速度/停止を接続する。公開用の名前付き保存・JSON操作・決定的リプレイ・バックアップ、手番順/配置/seed/難易度/方針を変えた公平性・CPU時間/入力応答/メモリ、従来2軍の退行検証を揃えてから最初のプレイ可能な4軍CPU観戦を公開する。
