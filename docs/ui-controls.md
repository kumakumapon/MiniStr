# 観戦・表示操作の改善

## 仕様

- CPU観戦中の「CPUをスキップ」は無効表示にする。通常の対CPU戦では利用可能。無効な操作をイベント処理でも拒否し、観戦の一時停止・再開と速度変更を利用する。
- マップ倍率に50%を追加する。100%は44px、50%は22pxのマス。初期倍率の自動選択は100%以上を維持し、手動縮小後はリサイズでも選択を保持する。50%ではユニット・HP・所属・状態・拠点の記号も縮小し、拠点の小さな補足文字を省く。詳細は選択したユニット／マスのパネルで確認できる。
- タイトルにCPU速度（0.5／1／2／4倍）を追加する。対局中の設定と同じタブ内で共有し、単体作戦・キャンペーン・観戦へ反映する。再読込時の既定値は従来どおり1倍。入力は利用可能な倍率だけを受け付ける。
- 既存の緑・金色のUIに合わせ、タイトルの操作欄に小さな選択欄を置く。戦場の表示領域を増設パネルで覆わない。

## 回帰確認

- 単体：スキップ可能条件、速度の許可値／不正値、共通速度選択欄、50%のマス寸法と既定倍率。
- UI統合：タイトルと対局の速度共有、タイトル復帰、不正な速度値の拒否。
- ブラウザ：PC（1280px）とスマートフォン幅（390px）のタイトル表示、フォーカス維持、単体作戦・キャンペーンへの速度反映。50%での選択・移動、画面幅変更後の倍率維持、100%への復帰。
- 観戦：スキップ無効、合成クリックの拒否、赤青の自動進行、一時停止・再開、プレイヤーセーブの保護。通常戦のスキップも既存テストで確認。
- Chromium・Firefox・WebKit共通：タイトル速度・50%・観戦操作を組み合わせて確認。高速CPUが操作途中で進まないようテストの時計を制御する。
- スクリーンショット：`systems-title-cpu-speed.png`／`systems-map-50-percent.png` をPC・スマートフォン幅で保存し、既存CIのスクリーンショット成果物に含める。

カバレッジ・UI統合・ブラウザ・lint・フォーマット・型・ビルド・リンク検査の実行結果はPRに記録する。ブラウザの画面幅を変更した検証であり、iPhone／iPad実機の操作確認は含まない。

## 変更範囲

仕様だけでドラフトPRを作成してから実装した。変更対象はUI操作と関連ドキュメント・テスト。保存形式・ゲーム規則・依存関係・CI設定の変更はない。CPU速度は同じタブ内で共有する既存変数を使用し、保存データには追加しない。

## タイトルからのマップ表示設定

- タイトルのCPU速度の隣に「マップ表示サイズ」を追加し、「自動」または50／75／100／125／150／200%を選べるようにする。
- 初期値は従来の画面幅に応じた「自動」。手動倍率は同じタブ内で作戦開始・再開・別作戦への変更・画面回転後も維持する。対局中の拡大／縮小とも連動する。
- 「自動」に戻すと画面幅と現在のマップに応じて再計算する。再読込時は自動に戻り、保存形式は変更しない。タイトルのマップ選択用プレビューの大きさはこの設定の対象外。
- 不正な倍率を拒否し、変更後も選択欄のフォーカスを維持する。既存の緑・金色のUIに合わせ、PC・スマートフォンで操作できる小さな選択欄にする。
- 単体・UI統合・ブラウザで、倍率の入力検証、対局との連動、単体作戦／キャンペーン／観戦への反映、自動への復帰、リサイズとフォーカスを確認する。

この追加仕様を先にドラフトPRへ記録してから実装した。回帰テストには、不正値や古いタイトル要素からのイベント拒否、保存対局の読込後の倍率維持、100／125／150%の自動切替も含める。PC・スマートフォン幅の選択欄を `systems-title-map-zoom.png` として保存し、検証結果とともにPRへ記録する。

## 複数軍の表示と操作（v1.6.1）

- **スマホ操作バー**。人間の手番では「ターン終了」を、操作中の人間軍からCPUを進めるときは「CPU進行」または「一時停止」を赤で示す。リプレイでは操作バーは非表示になり、再生用の操作を使う。
- **BGM**。開始画面と対局の作戦情報欄に「BGM設定」がある。オン／オフ、音量、共通曲、手番で曲を切り替える設定、第1〜4軍の曲を選べる。開始条件や端末引渡し中は共通曲、対局・観戦・リプレイでは表示中の手番の曲、戦闘シーン中は専用曲が流れる。設定はブラウザーに独立して保存し、全体バックアップに含める。この設定を含むバックアップの復元にはv1.6.1以降が必要。初回は通常2軍の音量・消音・共通曲の設定を初期値とする。
- **タイトル設定**。開始条件から新規対局を作るとき、タイトルのCPU速度と盤面倍率を使う。自動倍率は実際の盤面と画面幅で決まり、拡大・縮小・全体表示を手動で押すとその対局では手動倍率になる。読込では保存済みの速度を使い、倍率は100%から始まる。
- **地形・マス情報**。盤面下で凡例を開ける。マス選択で地形・防御を確認でき、自軍・味方の部隊を選んだときはその兵科の移動コストを表示する。仮設橋は通行コストに反映する。未索敵のマスでは部隊と占領の詳細を表示しない。
- **敵の脅威範囲**。軍別視点で盤面下のチェックを入れると、視認済み敵の攻撃が届き得るマスを表示する。味方と未発見の敵は計算しない。移動できる範囲は地形・橋・観測済みの占有・ZOCを考慮し、間接武器は現在地からの射程を使う。視界には現在の天候が反映される。敵の残弾・燃料や未発見の待伏せは非公開のため、範囲は目安。自軍部隊を選択中はその兵科に有効な武器へ絞る。全体視点では軍別視点を選んで使う。

複数軍では人間の操作担当が複数なら端末引渡しまで盤面を隠す。操作中の軍以外の視点は制限され、取消は人間1軍の同一手番内で戦闘・偵察・新しい視界をまたがない操作を最大8手まで扱う。通常2軍の取消が対CPU戦に限られる条件とは異なる。 [複数軍の保存・引渡し・取消](four-army-play-support.md)

## 対局の開始と設定

- **通常2軍**。ブリーフィングから作戦を開始すると盤面にフォーカスする。盤面下に偵察・補給・設営などの操作を置く。上部の「対局設定・保存」から、盤面下の戦域・難易度・CPU速度・保存操作へ移動できる。音量と演出設定はその下にある。「作戦情報」から勝利条件や未行動部隊を確認できる。
- **複数軍**。開始画面の先頭に戦域・操作担当・チーム・終了方式と開始ボタンを表示する。初回の既定は「緑の国境」、第1軍を人間が操作する4軍の個人戦、20ラウンド判定。「詳細設定」で戦域、参加軍、チーム、担当、規則、手番順、CPUなどを変更できる。「開始ボタンへ」で設定を閉じて開始ボタンへ戻る。進行中の対局がある場合は「進行中の対局へ戻る」も選べる。
