# 観戦・表示操作の改善

## 仕様

- CPU観戦中の「CPUをスキップ」は無効表示にする。通常の対CPU戦では利用可能。無効な操作をイベント処理でも拒否し、観戦の一時停止・再開と速度変更を利用する。
- マップ倍率に50%を追加する。100%は44px、50%は22pxのマス。初期倍率の自動選択は100%以上を維持し、手動縮小後はリサイズでも選択を保持する。
- タイトルにCPU速度（0.5／1／2／4倍）を追加する。対局中の設定と同じタブ内で共有し、単体作戦・キャンペーン・観戦へ反映する。再読込時の既定値は従来どおり1倍。入力は利用可能な倍率だけを受け付ける。
- 既存の緑・金色のUIに合わせ、タイトルの操作欄に小さな選択欄を置く。戦場の表示領域を増設パネルで覆わない。

## 確認予定

単体・UI統合・PC／スマートフォンのブラウザ確認。観戦の無効操作と通常戦のスキップ、50%と拡大復帰、タイトル設定の反映・フォーカス・不正値拒否を確認する。既存のcoverage・lint・型・ビルド・CIも確認する。

## 作業順序

この仕様だけでドラフトPRを作成し、その後に製品コードを修正する。保存形式・ゲーム規則・依存関係・CI設定は変更しない。
