# 観戦・表示操作の改善

## 仕様

- CPU観戦中の「CPUをスキップ」は無効表示にする。通常の対CPU戦では利用可能。無効な操作をイベント処理でも拒否し、観戦の一時停止・再開と速度変更を利用する。
- マップ倍率に50%を追加する。100%は44px、50%は22pxのマス。初期倍率の自動選択は100%以上を維持し、手動縮小後はリサイズでも選択を保持する。50%ではユニット・HP・所属・状態・拠点の記号も縮小し、拠点の小さな補足文字を省く。詳細は選択したユニット／マスのパネルで確認できる。
- タイトルにCPU速度（0.5／1／2／4倍）を追加する。対局中の設定と同じタブ内で共有し、単体作戦・キャンペーン・観戦へ反映する。再読込時の既定値は従来どおり1倍。入力は利用可能な倍率だけを受け付ける。
- 既存の緑・金色のUIに合わせ、タイトルの操作欄に小さな選択欄を置く。戦場の表示領域を増設パネルで覆わない。

## 回帰確認

- 単体：スキップ可能条件、速度の許可値／不正値、共通速度選択欄、50%のマス寸法と既定倍率。
- UI統合：タイトルと対局の速度共有、タイトル復帰、不正な速度値の拒否。
- ブラウザ：PC（1280px）とスマートフォン幅（390px）のタイトル表示、フォーカス維持、単体作戦・キャンペーンへの速度反映。50%での選択・移動、画面幅変更後の倍率維持、100%への復帰。
- 観戦：スキップ無効、合成クリックの拒否、赤青の自動進行、一時停止・再開、プレイヤーセーブの保護。通常戦のスキップも既存テストで確認。
- Chromium・Firefox・WebKit共通：タイトル速度・50%・観戦操作を組み合わせて確認。高速CPUが操作途中で進まないようテストの時計を制御する。
- スクリーンショット：`systems-title-cpu-speed.png`／`systems-map-50-percent.png` をPC・スマートフォン幅で保存し、既存CIのスクリーンショット成果物に含める。

カバレッジ・UI統合・ブラウザ・lint・フォーマット・型・ビルド・リンク検査の実行結果はPRに記録する。ブラウザの画面幅を変更した検証であり、iPhone／iPad実機の操作確認は含まない。

## 変更範囲

仕様だけでドラフトPRを作成してから実装した。変更対象はUI操作と関連ドキュメント・テスト。保存形式・ゲーム規則・依存関係・CI設定の変更はない。CPU速度は同じタブ内で共有する既存変数を使用し、保存データには追加しない。
