# 全10作戦の攻略・難易度調整（2026-10-15）

## 方法と結果

標準と易しい設定で、それぞれ新規キャンペーンから全10作戦を連続クリアした。標準は6,179命令、易しい設定は5,759命令。勝利ごとの実際の評価・出撃支援・経験部隊を次作戦へ引き継いだ。敗北後の強制解放、初期状態の改変、HP・資金の書き換えは行っていない。

赤軍の参照操作者は既存のhard CPU。青軍は指定した難易度で動かす。両軍ともUIと同じ正規コマンド、霧の制約、1手番の命令数上限を使う。正規初期状態の乱数seed=1を使い、全勝利リプレイの再生検証も通す。人による全ターンの手動攻略や複数シードでの勝率測定ではない。ターン数は結果画面の値、損失はリプレイ集計の配置済み部隊の撃破数で、輸送中の貨物喪失は含めない。

## 停滞の原因と調整

調整前のPR #196では、同じ参照操作者で標準設定の10作戦を個別診断し、峡谷・凍土・前哨地の3作戦だけが勝利した。診断を続けるため、当時の敗北後は仮のA評価で次を開いた。この初回診断は連続攻略の成績には含めない。

- **占領場所の渋滞**：弾切れの航空機や間接砲が未占領の工場へ居座り、歩兵が入れなかった。占領できない部隊は場所を譲る。重傷の占領部隊は、近くに健康な交代要員がいれば交代する。
- **補給と射撃位置**：弾切れ部隊が前線へ向かい続け、間接砲が最小射程の内側へ進んでいた。互換性のある補給先への距離と、次ターンに射撃できる位置を評価する。
- **工業地帯の片側集中**：確保済みの工場へ全軍が集まっていた。保持中の守備隊を残し、後続部隊を空いている目標へ向ける。
- **輸送の循環・停滞**：中継島で乗降を繰り返す、輸送艦と歩兵が集合しない、港を輸送艦が塞ぐ問題があった。近い地上目標を先に処理し、集合・迎え戻り・沖合からの上陸・港の空け渡しを改善した。移動済み歩兵への二重移動命令も防ぐ。
- **海上戦力と港**：群島戦には艦砲支援と輸送隊、上陸戦には護衛・艦砲支援・航空護衛・第2輸送隊を配備した。上陸戦の内陸港を沿岸へ移し、北岸軍港 (14, 5) の確保と3ターン保持を主目標にした。敵工場・空港は残す。
- **制圧火力と期限**：国境・包囲・渡河・工業・湿地に作戦用の間接火力・補給を用意した。包囲戦の期限は44→50、最終湿地戦は40→48に変更した。
- **航空機だけでの保持**：新規キャンペーンでは地上部隊の保持を必須にした。所有権が必要な港は輸送艦だけでも達成できない。旧保存条件は変更しない。

## 難易度比較の読み方

難易度は既存の生産上限（easy 45% / normal 70% / hard 100%）と、移動後攻撃の計画範囲で差を付ける。敵のHP・ダメージ・索敵情報に追加の特例は設けていない。

別途、**標準攻略で各作戦直前に得た同じ評価・経験**を固定して3難易度を比較した。参照操作者の勝利はeasy 9/10、normal 10/10、hard 7/10。hardでは国境・上陸・最終湿地が期限超過、凍土の損失は標準13→hard33、工業は5→14になった。

同じ操作者でも、敵の行動や生還部隊が変わると進路と戦闘結果が変わる。固定した標準の継承部隊ではeasyの包囲戦が期限超過した一方、easyを最初から進めた実際の継承部隊では35ターンで勝利した。個別作戦のターン数は難易度順に単調には並ばない。上記を人間の勝率やhard全作戦の攻略保証とは扱わない。標準の攻略可能性とeasyの連続攻略を回帰基準とする。

## 再現と回帰確認

```sh
npm run campaign:playthrough -- normal /tmp/ministr-campaign-normal
npm run campaign:playthrough -- easy /tmp/ministr-campaign-easy
npm run campaign:playthrough -- compare /tmp/ministr-campaign-compare
npm run test:coverage
npm run build
npm run test:ui
npm run test:e2e
```

通常実行は敗北した作戦で停止し、終了コード1を返す。各作戦の検証済みリプレイ、初期／最終状態・命令の診断記録、成績表、実際のキャンペーン進行を指定先へ出力する。`compare`は標準の勝利だけで進行し、easy/hardの結果を進行へ混ぜない。

- 単体テスト：全10作戦の標準連続攻略、実際の評価・経験継承、リプレイ検証、配置地形と重複、地上保持・所有権・旧条件の互換性、CPUの占領・補給・砲撃・輸送の停滞を確認。
- ブラウザ：PC 1440px／スマートフォン390pxのブリーフィングと手番操作、青軍手番の保存からの自動再開、全10作戦の正規の直前セーブから最後の操作・評価保存・解放を確認。全10本の勝利リプレイをUIから取り込み最終手までシークする。序盤からの全命令は上記の参照操作者で生成し、ブラウザ側で全ターンを手動操作したとは報告しない。
- スクリーンショット：`campaign-turn-controls.png`、`campaign-cpu-resumed.png`、各作戦の`*-victory.png`をPlaywrightの出力先に保存。CIの`browser-failure-traces`アーティファクトにも保存される。
