# v1.1.0 作業記録（未完了）

基準: v1.0.0 / 971ea082。ドラフトPR #246。

橋の破壊の候補実装を追加しました。ルールv12に限定し、既定の新規対局は全機能完成までv11のままです。未移動・未行動の隣接工兵で空き仮設橋を破壊し、返金なしで行動を終了します。占有中・旧ルール・範囲外・敵の工兵の操作を拒否します。地形そのものを書き換えません。

CPUは確認済みの地上敵が近い敵軍の橋を対象とし、ほかの味方地上部隊が近い場合は残します。日英の確認ダイアログ、観戦カメラ、公開イベントのリプレイ表示にも対応します。

ローカルでは既設のVitest3.2.7を使用し、橋の破壊11件と既存の橋・UI35件、計46件が成功。型検査・lint・書式・ビルド・リンク検査も成功しました。lockfileのVitest5での全回帰、ブラウザ導線、全作戦評価、旧ルール比較は未完了です。
