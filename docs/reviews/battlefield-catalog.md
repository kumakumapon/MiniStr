# 戦域一覧の分類と絞り込み（#342 案B）

戦域カードを選ぶと、その条件の開始画面を開きます。最初は「すべて」を表示します。通常2軍は従来どおり、戦域カードと「作戦開始」の2操作で始められます。

| 項目 | 表示と判定 |
| --- | --- |
| 分類 | 対戦、作戦・任務、戦術演習、生成・カスタム。標準マップ、単体作戦、演習、ユーザー保存と複数軍専用の各カタログから組み立てます。 |
| 軍数 | 対応する2・3・4軍を表示します。「3軍」で選んだ戦域は3軍の開始画面を開きます。 |
| 盤面サイズ | 長辺が18マス以下は「小」、19〜31マスは「中」、32マス以上は「広域」です。通常版と複数軍版で寸法が異なる場合は両方を掲載します。 |
| 地形 | 水域を含む盤面と陸戦用の盤面を区別します。季節や沿岸などの地形テーマもカードに表示します。 |
| クリア状況 | 単体作戦の同じシナリオ改訂に勝利記録があれば「クリア済み」です。対応作戦の初回は「未クリア」、記録を取らない対戦やカスタムは「クリア記録対象外」です。 |
| 組み合わせ | 軍数・盤面サイズ・地形は同じ対戦形式にすべて一致することが表示条件です。 |
| 操作 | 分類タブは左右キー、先頭と末尾はHomeとEndで選べます。戻った時は絞り込みを保持します。 |

390px幅では2列で戦域を比較できます。広域カードの縮小図には地形色と所有軍別の拠点マーカーを使います。開始画面の地図は従来の詳しい描画を使用します。
