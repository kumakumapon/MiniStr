# 地形表示・陣営別BGMの確認記録（2026-10-24）

## 対象

基準は公開済みv0.9.3の`a11ae1d965d05f07b70f9d97a4889dcc19539893`。計画のみのドラフトPR #229を作成してから実装しました。ゲーム・CPU・シナリオの規則は変更せず、地形画像の参照とテーマ処理、音楽・設定・凡例を変更します。最終対象SHA・CI実行結果は[PR #229](https://github.com/kumakumapon/MiniStr/pull/229)に記録します。

## 地形

- 既存CSSでテーマの背景色より後に共通のアトラスが上書きされ、テーマ別の単色縮小図と盤面が一致していませんでした。
- 森・山・道路のアトラス参照列も、実際の画像に対して1列ずれていました。画像を確認して列1・2・3へ合わせました。平原は従来の重複平原セル（列3・行2）を使います。
- 共通モジュールからアトラス・切り出し位置・地形だけのテーマフィルタを出力し、部隊や施設の所有者表示へフィルタを掛けません。
- 縮小図のセルごとにSVG画像を増やす初期実装では、一覧再表示を繰り返す画面統合テストが重くなりました。地形ごとのパターンと行内の連続セルを再利用する方式へ変更し、既存の時間予算を維持します。
- ブラウザテストは全5テーマ×PC1280px／スマートフォン390pxを対象に、実際の縮小図と盤面画像を同じ寸法で描画し、6地形の平均RGBの最大差が8未満であることを比較します。施設の所有者・初期部隊の簡略マークは画像比較から除き、単体と通常画面で確認します。
- 比較ではポインターを盤面外へ移し、ホバーの明るさ補正が色差に混ざらないようにします。閾値を変えて回避しません。
- 初回の完了CIでは153件成功、WebKitのテーマ付き縮小図だけ8件が失敗しました。SVGパターン内部へ適用したCSSフィルターの互換性問題を確認し、パターンを無加工の画像にして、実際に描画する地形矩形へ同じフィルターを適用する方式へ修正しています。矩形へ移すだけではWebKitの同じ8条件で改善しなかったため、最終方式では共通の色変換からsRGBのSVG標準フィルター（行列・彩度・色相回転・明度）を生成します。HTML盤面のCSS変換とSVG縮小図の標準変換の出力を、同じ画像比較で確認します。画像比較の閾値・対象ブラウザは維持します。

## 音楽

[生データ](2026-10-24-rock-audio.json)にffprobe情報、音源・WAV・生成スクリプトのSHA256を保存しています。

| 曲 | BPM | 秒 | ピークdBFS | RMS dBFS | デコード後の境界の最大サンプル差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 烈火 | 160 | 24.000000 | -5.6660 | -17.7316 | 0.007976 |
| 蒼雷 | 148 | 25.945941 | -5.2066 | -17.9222 | 0.004955 |

両曲ともOgg Vorbis、44100Hz、ステレオです。歪みギター、パワーコード、ベース、バックビート、ハイハットとフィルを合成しています。残響の折り返しと両端4msの窓により、境界のサンプル段差を抑えています。上表は出音の工学的な検査で、音楽性や実機の聴感を保証する数値ではありません。旧曲と戦闘専用曲のファイルは変更していません。

```sh
# 作業ディレクトリでWAVを生成（引数の順番によらず各曲のseedは独立）
node /path/to/scripts/generate-music.mjs rock-red rock-blue
ffmpeg -i rock-red.wav -af volume=-5dB -c:a libvorbis -q:a 3 rock-red-theme.ogg
ffmpeg -i rock-blue.wav -af volume=-5dB -c:a libvorbis -q:a 3 rock-blue-theme.ogg
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_name,sample_rate,channels -of json rock-red-theme.ogg
```

逆順の指定によるWAV再生成でも両曲のSHA256が一致しました。Oggのコンテナ識別子はエンコーダにより変わるため、再エンコード時のバイト列一致は要件にしません。

## 回帰対象

- 旧BGM設定の音量・ミュート・選曲、両軍の選曲と共通方式、設定の保存・再開・保存失敗。
- 1つの実際のAudio要素を監視し、タイトルでの試聴、戦闘専用曲への切り替え・スキップ後の再生復帰、赤青の手番交代、共通方式での継続をブラウザで確認。新曲のメディア読み込みも確認します。
- 再生拒否・未解除・音量0・ミュート、曲別の位置復帰、戦闘中の設定・陣営変更、遅い再生要求は単体テストで確認します。
- BGM変更で対局状態・コマンド列・ルールv10が変わらないこと、全組み込み作戦の英語UI、保存・リプレイ・観戦・キャンペーン・表示操作の回帰を確認します。
- JSDOMで配布用JSを評価する既存の統合テストには、Viteが画像URLに使う`import.meta.url`を実際の配布モジュールURLとして与える共通ヘルパーを追加しました。アプリのコードと既存アサーションは維持し、実際のESモジュール読み込み・画像デコードはブラウザで確認します。
