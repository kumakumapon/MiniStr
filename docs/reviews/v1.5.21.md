# v1.5.21：小型3・4軍の検証記録

## 固定した比較

小型「緑の国境」3軍／4軍、未使用seed152101〜152103、各軍normal／balanced、戦術ON/OFF、3軍全6順／4軍全24順の180条件を、20Rの短期戦で比較する。軍ID別・開始手番別を分けて集計し、引分と判定勝利を全滅勝利へ読み替えない。同seedの順番違いを独立した確率試行とみなさず、少数seedから公平を保証しない。

代表条件は64命令でschema5へ保存し、全履歴・軍別履歴を検証して読込後の最大64命令の判断・盤面・RNGを照合する。早期終局は比較長として記録する。旧32×32はv1.5.20の16条件の512命令prefix・64命令継続hashへ照合する。

## 画面検証

配布bundleを使い、PC1280px／スマホ390px・日英で3／4軍の開始、252マス、手動／自動保存と読込、undo、20R終局、同条件再戦、3軍の人間交代とCPU区間の視界保護を確認する。画像はE2E成果物の `v1521-compact-*`。

ローカルではTypeScript5.9／Vite7／Vitest3・system Chromiumを補助に使用し、正式なTypeScript6／Vite8／Vitest5と3ブラウザはCIで検証する。ローカルのjsdom依存の入手が制限されているため、DOM単体を未実施のまま成功扱いにはしない。

## 結果

比較レポートと正式CIの完了後に実測値を記録する。

## 次の対応

1. 実測で残る配置・手番順の差を診断し、初期条件または新CPU版で限定改善する。旧版を維持する。
2. 人間1軍で物理PC／スマホの20〜30分の試遊目標を検証する。従来の実時間2／4時間・支援技術・長期保存評価も別途継続する。
3. 初版の評価後、「前哨基地強襲」等の派生マップを追加する。
4. 任意の軍の不参加設定、32盤面の3軍化、途中の人間↔CPU切替を個別に仕様化する。
5. 水域・港・橋、同盟／共有視界／チーム勝利、任意盤面・研究分岐等は個別に採用判断する。

新しい小型対局の提供を、v1.5.20で残った従来規則26条件の400R打切り解消や、公平性／物理実機評価の完了としては扱わない。
