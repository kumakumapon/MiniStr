# v1.3.0 実装計画

基準: v1.2.2 / main a273a8962099a581ccabbe859d13cb0bbf4ea616。
関連Issue: #168（総合）、#213（戦闘・拡張）、#155（原レビュー）。

## 採用範囲
1. 依存・CI: jsdom更新候補#253のNode互換性を解決。minimatch等の監査を再評価し、正式lockfileのクリーン導入・依存整合・監査・全品質ゲートを確認。現行Node互換性・公開条件・権限を維持する。
2. CPU・バランス: v1.2.2を基準に未使用seed・戦闘乱数・先後・16/20/32盤面・海域・方針・難易度を比較。悪化条件を含む全rawを記録し、結果に基づく限定的改善を採用する。
3. 操作応答: 観戦p95、ユニット選択、初回読込を計測し、実測されたボトルネックを改善。速度とメモリ・再計算のトレードオフを記録する。
4. 戦闘3案: 隣接同時攻撃（攻撃側の優位を含む）、視界差の奇襲・反撃制限、山/平原/道路の防御補正をまとめて仕様化。評価用モデルで個別・組合せを比較し、CPU・先後バランスへの影響と採否を記録する。既定のゲーム規則への導入は評価の採否と互換性設計に基づいて判断する。

## 検証・完了条件
- 対象を固定し、単体/coverage、配布UI、3ブラウザ、WebKit反復、Node互換性、CI公開条件、型/lint/整形/build/リンク検査とCodeQL結果を確認。
- 記録済みのリプレイ、保存schema4、キャンペーンschema5を保護。規則変更を採用する場合は旧版再生を維持する。
- 比較のraw・条件・失敗・不採用案・制約を保持。実機iPhone/iPadは低優先度を継続。
- package/lock/公開ノート等を1.3.0に同期し、最終PRをレビュー可能にする。
- マージ後mainのCI/CodeQL/Pagesと同一SHAを確認して正式Release v1.3.0を準備する。
