# 有限補給の比較記録（2026-10-23）

## 対象と再現

v0.9.2の公開ソース`db9fa9cfc2aa4fee500c9c460c6bb982449e4084`を基にしたPR #228の実装です。ルールv9（従来無制限）とv10（物資300）の両方を同じ新ソースで動かし、有限補給と対応CPU分岐の差を比較します。旧バイナリとの比較ではありません。実行時のゲーム・CPU・スクリプトのSHA256は[生データ](2026-10-23-finite-supply-results.json)に記録しています。

```sh
npm run supply:compare -- docs/reviews/2026-10-23-finite-supply-results.json
npm run campaign:playthrough -- normal /tmp/ministr-v093-campaign-normal
```

比較は単体11作戦の既定seed・赤hard/青easy（22対局）、補給争奪・峠・橋頭堡・撤退の4作戦×seed 7919/15838・両軍normal（16対局）、前線生成16サイズ・coast・seed stock-check-A/B・両軍normal（4対局）の合計42対局、21組です。合法コマンドだけを適用し、1手番120操作超過や補給物資の説明できない増加はエラーにします。比較は最大60ラウンド、境界の第61ターンでの判定勝利を含みます。

## 観測結果

- 全42対局で決着し、21組とも勝者・勝因・決着ターンが一致しました。
- 有限側21対局の物資消費は合計2712、補充量545、補充11回、在庫が0になった事象1回でした。
- 既定seedの単体11作戦は両方式とも赤軍が目標達成しました。これは攻略用CPU条件であり、同格対戦の公平性を意味しません。
- 生成2条件は赤1勝・青1勝で、条件数が少なく先後のバランスを推定できません。
- 物資上限300を採用し、今回の標本では作戦目標や初期兵力の追加調整は行いませんでした。長期の補給遮断や大量の砲撃では影響が増えるため、枯渇・部分補給・帰投は単体テストでも直接検証します。
