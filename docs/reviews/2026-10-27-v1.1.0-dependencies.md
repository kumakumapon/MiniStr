# v1.1.0の依存監査

2026-10-27にCIで最新npm auditを取得しました。[監査の生データ](2026-10-27-v1.1.0-audit.json)。更新前は全依存5件（high2・moderate3）、本番依存0件。対象はVite、Vitest/coverage/mocker、jsdom経由のundiciでした。

- Vite: `^6.4.3` → `^6.4.4`（lockfileの解決版は6.4.5）。dev server / launch-editor等の修正。Vite 8へのmajor更新は今回必要ありません。
- Vitest本体とcoverage: 5.0.2 → 5.0.5。互換性のある同じ版に揃え、mockerの修正を含みます。設定のprojects方式と既存のカバレッジ基準を維持します。
- undici: 7.30.0 → 7.30.1。jsdomの既存依存範囲 `^7.25.0` 内で更新し、新しい直接依存や強制overrideは追加していません。

更新後の[CI #474](https://github.com/kumakumapon/MiniStr/actions/runs/40491466550)で、全依存・本番依存ともに0件。単体1256件、UI統合56件、3ブラウザ279件が成功しました。このrunは候補lockfileをCIで生成して検証したものです。取り込んだlockfileからのnpm ciと最終の追加修正を含む結果はPR #246の最終CIを参照してください。

ローカルのレジストリ通信制限により、lockfileはCIのnpmで生成し、出力した完全なbase64をAPI経由で取得して復号しました。rootの版とdevDependenciesがpackage.jsonと一致することを検査しています。一時的な生成ステップは削除し、最終CIはコミット済みlockfileに対するnpm ciを使います。

これらは開発・テスト用依存で、公開物は静的なdistです。今回の監査は利用者への悪用を確認したものではありません。将来dev serverの外部公開やサーバー配信へ構成を変える場合は再評価します。

以前のVitest・Viteに関する期限付き監査例外は、この更新と最新監査0件の結果で解消します。過去の監査記録は当時の履歴として保持します。未修正の指摘を期限延長で済ませる判断はしていません。
