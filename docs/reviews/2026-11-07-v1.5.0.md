# v1.5.0 兵站運用の確認記録

基準はv1.4.9/main ec1adf4c1f6d126337edfd7e4fea298460f67351。計画のみのDraft PR #270を先に作成した。

## 実装

ルールv14に部隊別の優先・燃料／弾薬優先・修理許可と軍別の修理留保資金を追加した。設定は独立した検証付きコマンドで、元状態を変更せず記録する。既定値は従来の配分順と修理。旧ルールでの設定混入、不正値、敵部隊への指示、終局後の変更を拒否する。敵の設定をCPU観測から除去する。

一覧は閉じた状態で部隊詳細や補給予測を作らない。自軍の行動済み・搭載部隊も含み、現在配置・施設・収入の条件付き予測を表示する。保存／再開、取り消し、リプレイは同じ設定コマンドから再構築する。

## ローカル検証

- 物資競合・燃料優先・修理保留／留保資金・不正入力・旧版拒否・JSON再現・実保存／リプレイ書き出し読み込み・CPU攻略を専用テストで確認。
- 単体作戦「戦術演習・限られた物資」は難しい赤CPU対易しい青CPUが合法な操作で保持勝利。指定設定は任意の学習課題であり、勝利条件への強制ではない。
- PC1280幅・390幅、日英のChromium／Firefoxで、指定・部隊選択・保存と再起動後の設定保持・横溢れなしを確認。新規操作8件と、既存の有限／無制限補給4件が成功。
- ローカルは既設Vitest3.2.7/Vite6の参考実行。正式lockfileのVitest5/Vite8・監査・3ブラウザー結果はPR #270の最新CIを参照する。環境のnpm registry通信は制限され、ローカルのクリーン導入と最新監査は実施していない。

## 互換性・範囲

新規通常戦・単体作戦の有限補給はv14。日替わり・キャンペーン・無制限補給と、保存済み対局の規則は保持。一覧は旧対局でも利用でき、指定はv14だけ有効。保存・リプレイschema4を維持し、旧アプリは未知v14を安全に拒否する。素材・依存・CIの品質閾値・公開条件は変更していない。
