# 生成マップのバランス比較（2026-10-19）

## 条件と読み方

生成方式v1（`baseline`、戦闘seed固定1）とv2（`seeded`、生成条件から戦闘seedを導出）を、同じ地形・部隊・青軍補償2000Gで比較した。双方ともルールv7、CPU普通対普通。16×12・20×14・24×16、海域なし・沿岸・多島、生成seed `verify-1`〜`verify-4`・`release-a`・`release-b`、通常と180度回転の計216対局（各版108）。上限60ラウンド、120命令/手番、1200秒。

回転は地形と部隊を同時に回し、陣営の先後は維持する。同じ生成seedの回転対局は対応のある条件であり、216個の独立標本ではない。到達距離は地形だけを使った歩兵の最寄り中立施設までの移動コストで、交通・射撃・資金・占領の成否は含まない。60ラウンド後の判定で状態が次の61ターンを示す場合もある。

この初回の216対局は設計コミット `fba8664f7284aa243bb0c6bb305a63d8211e75c5` からの**未コミット実装**で実行した。SHAだけで実装を特定できないため、ソースのSHA256も保存する：`b965bf5f2b57ab5e8bd4b5475ab450713097de58c0abcab92856681cf9a31feb`。確定コミットの再実行結果を追記する。

## 採用した変更と見送った調整

- **採用**：v2はマップ生成の条件から戦闘の乱数開始値を分ける。v1で全生成マップが同じ戦闘seed1を共有していた偏りを避け、地形と戦闘の再現条件を明示する。保存済みv1の定義・開始資金・戦闘seedは維持する。

- **見送り：道路の拡幅**。ルールv6、16×12、生成 `tune-1`〜`tune-3`、戦闘7919/15838の36対局。元方式は全海域で各赤2/青4だったが、拡幅では海域なし赤5/青1、沿岸赤4/青2、多島赤5/青1。赤有利を強めた。

- **見送り：補償1000G**。調整用54対局では多島の青2000Gが赤2/青4、1000Gが赤4/青2だった。しかし未使用生成 `check-1`〜`check-4`、戦闘23757/31676、両方向の32対局では1000Gが赤15/青1、2000Gが赤9/青7。20/24サイズ・別seedの追加16対局でも1000Gの一貫した改善はなく、2000Gを維持した。

- v7の先行評価48対局ではv1赤16/青8→v2赤13/青11。一方、別seedと全サイズ36対局では赤10/青8→赤12/青6だった。この逆方向の結果を踏まえ、単一の小標本だけで公平化完了とは判断しない。

## 再現コマンド

```bash
npm run balance:compare -- --generated \
  --sizes 16,20,24 --seas none,coast,ocean \
  --seeds verify-1,verify-2,verify-3,verify-4,release-a,release-b \
  --damage-seeds scenario --orientations normal,rotated \
  --variants baseline,seeded --rule 7 --max-games 256 --seconds 1200 \
  --output /tmp/ministr-generated-balance.jsonl
```

JSONLには条件、解決した戦闘seed、開始ソースのダイジェスト、各対局の勝因・ターン・命令・時間・初動・初回占領と完了状態を出力する。`--damage-seeds 7919,15838` なら共通の戦闘乱数で地形・資金の変更だけを比較できる。`--matchups hard:normal,normal:hard` で難易度の交換も指定できる。大きすぎる組合せと不正オプションは開始前に拒否し、時間切れは未完了と出力する。

## 残る評価範囲

今回の216対局は普通対普通のCPU評価。人間同士、全難易度の交差対局、全seed、大規模長期戦までを公平と判定するものではない。次は固定した評価seedを保ったまま、難易度の交換・追加seed・人間プレイを比較し、初動と射線の偏りを個別に調べる。Issue #213で継続管理する。
