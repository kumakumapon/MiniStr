# v1.5.14 確認範囲

CPU・ゲーム規則・2軍/研究保存の受入上限を維持し、4軍の公開保存形式、検証処理、リプレイのメモリーと記録の再書出しを変更する。既存CI/Pagesの条件・権限・timeout/retryは維持する。

[88条件の実測](https://github.com/kumakumapon/MiniStr/actions/runs/43496013540)は全12分割が成功。全24順×3seedで50勝利/22未決着、混合12条件で10勝利/2未決着、既知seedの1,000ラウンド継続4条件で3勝利/1未決着。合計63勝利/25未決着。全命令の適用、各軍16部隊の上限、100ラウンド後の明示再開を確認。基準はv1.5.13のengine2/CPU v1で、本版のCPU/対局規則と同一。CPUの改善や公平性の合格を主張するデータではない。

検証する境界は、全10命令と武器指定の圧縮往復、不正辞書/タプル/未知版/改ざん拒否、旧保存の明示移行、1MB/8MB/65,536命令、検証・位置移動の取消、キャッシュ上限、保存容量不足、対局置換による書出しキャッシュの破棄、全データ復元の原本保全。

ブラウザの長期試験は `npm run test:four-army-endurance` で再現する。通常E2Eと別の明示的な重負荷試験で、通常CIの既存timeoutやリトライは変更しない。最大記録の読込/保存/再読込と取消、同総部隊32/64の合成CPU比較、390pxで10分の実Worker操作を対象とする。CPU時間は別アルゴリズムの比較で、同等な対局や勝率の比較ではない。停止入力はpointerdownから処理後の描画まで、heapはChromiumの明示GC後を測る。物理端末やFirefox/WebKitのheap値を推測しない。

全単体/coverage・配布物UI・既存を含む全E2E・Node22.13・CodeQL・同一SHAのPages公開をリリース条件とする。実行結果とスクリーンショットは実装PRと公開時のIssue #264/#275へ記録する。未実行・未完了を成功扱いにしない。
