# v1.5.24：占領・補給演出と独立した表示設定

## 原因と修正

4軍の確定命令後のUIは、v1.5.23で戦闘要約からバトルシーンを表示するようになったが、占領・手番開始の補給差分を共通の `ActionScene` へ渡していなかった。占領自体や補給処理はエンジンで実行されている。

確定前後の状態を読み取り専用で2色の表示形式へ投影し、従来の占領・補給抽出を共用する。元の軍・部隊IDを保持し、表示時は第1〜4軍の名前・色を使う。補給は実際に増加した耐久・燃料・主／副武器弾薬だけを表示し、施設・補給車・輸送などの補給元を付ける。表示のための命令再適用、手番開始の再実行、乱数消費はしない。

戦闘と共通のモーダル管理へ整理し、背景の入力停止、時間切れ・スキップ・Escape、フォーカス復帰、CPU／自動再生の待機を扱う。戦闘直後に手番開始の補給がある場合も順に表示し、停止・メニュー・読込・画面離脱などで保留分を取り消す。戦闘音声は戦闘だけに適用する。再生の1手送りでも確定差分を取得し、大きなシークでは途中の演出を連続再生しない。

制限視点では前後の実観測で部隊を確認し、占領位置の可視性を確認する。補給資源・搭載情報は自軍／味方軍だけとし、敵部隊の詳細を公開しない。複数人の端末交代では情報を隠し、次の人の操作開始後にその軍の補給を表示する。

## 設定と互換性

新しい `ministr.actionScene.settings` は `twoArmy`／`multiArmy` の真偽値だけを受け付け、どちらも初期ON。従来のバトル設定と独立し、他方のモードを上書きしない。保存失敗は現在の画面に反映して通知する。全体バックアップへ検証付きで追加し、旧バックアップは設定なしでも利用できる。新設定を含むバックアップの復元にはv1.5.24以降が必要。

ゲーム規則・エンジン・経路・CPU・対局の保存形式と履歴検証は変更しない。通常2軍は表示設定の追加だけとし、既存の占領・補給の解決処理を維持する。OFFでは4軍の追加差分抽出・演出待機を省く。

## 検証と限界

- 設定の独立保存、破損値の拒否、保存不能、バックアップ・旧バックアップ互換を検証する。
- エンジンで解決した占領の途中／完了、施設修理・補給車、主／副武器、未知部隊と敵情報の非公開、通常命令・100R停止／再開の表示抽出を検証する。前後の状態を抽出前後で比較し、表示情報が保存状態へ混入しないことを確認する。
- モーダルの期間・時間切れ・スキップ・OFF・一時停止・メニュー・Escape、背景入力とフォーカス復帰を検証する。画面統合では1回だけの命令適用と端末交代後の補給を確認する。
- 実ブラウザーはPC1280px／スマートフォン390px、日英で占領進捗、OFF／ONの同一結果、独立設定・再読込、キャッシュ利用の1手再生、CPU補給の待機／取消、2軍・4軍の端末交代を検証する。`systems-four-action-*`、`systems-two-action-*`、`systems-four-supply.png` を成果物に残す。Firefox／Chromium／WebKitへ同じ新規ケースを追加し、既存のバトル演出回帰も実行する。
- ローカル補助環境はNode24.19・TypeScript5.9.3・Vite7.3.6・Vitest3.2.7・Playwright1.63／system Chromium。固定依存・JSDOMの取得制限があるため、固定依存での全単体・カバレッジ・配布UI・3ブラウザー・Node22.13・通常ビルド・依存監査の正式結果はPR／main CIとReleaseの公開証跡へ記録する。ローカルビルドは欠落した暗黙の型依存を避け、明示したvite/client型での補助検証を実施する。CIの基準・権限・時間上限・監査・Pages公開条件は維持する。

## 次の対応残件（推奨順）

1. **3軍北側の偏りと未決着の残6条件**、固定チーム・水域の公平性を診断し、限定CPU改善を比較する。
2. **物理PC／スマートフォンで20〜30分の実戦評価**。入力・視認性・演出設定・音声復帰・端末引渡し・保存再開を評価する。
3. **水域／チーム戦の長期記録とCPU運用**。輸送・工兵、保存・再生の長期継続性を検証する。
4. **途中参加／退出、任意地形、潜水艦、動的同盟**は参加条件・保存互換・勝敗仕様から検討する。

4軍の占領・補給・修理演出の共通化は今回対応した。全体の残件18群（改善8／機能9／保留1）と機能追加9群の分類は維持し、下位項目の完了を別の残件として再計上しない。自動ブラウザー検証を物理実機での実戦・公平性の再評価とは扱わない。正式公開後にIssue #264・#275を更新し、次の実装は開始しない。
