# v1.5.13 確認記録

## 変更範囲

4軍専用の開始メニュー・観戦画面と公開用の基本保存操作を追加。2軍のゲーム規則、CPU、研究形式、CI/Pagesの公開条件・権限を変更しません。3ブラウザの既存E2E対象へ新しい画面テストを追加します。

## 検証対象

- 保存形式の不正入力、固定条件・履歴・最終状態の照合、未知バージョン、1MB/2,048命令の境界、全データ復元の事前検証。
- ファイルWorkerの中断・古い応答の破棄、リプレイの再現・位置移動・取消、軍別表示の情報制限。
- 画面からの開始、seed/手番の入力検証、CPU設定・視点・速度、停止/1手/再生、キーボード、拡大縮小、タイトルへの復帰。
- PC 1280px / スマートフォン390px、日本語/英語、reduced-motion、盤面スクリーンショット。
- 実モジュールWorkerの取消、専用保存2枠・JSON・再読込、通常データの保持、容量超過、100ラウンドの明示再開、記録上限。
- lint / format / テスト型チェック / 全単体テストと既存coverage閾値 / build / 配布物UI統合 / 全E2E / Node22.13互換 / CodeQL / 同一main SHAのPages公開。

## 判断範囲

短い画面・取消テストは、4軍対局の公平性や長時間の端末メモリーを証明しません。24手番順・複数seed・難易度/方針の長期比較と、2,048命令を超える記録の拡張は次段階です。既存のCI閾値・タイムアウト・リトライ方針は維持します。

CI実行結果と画面証跡は当版の実装PR、リリース時のmain CI、Issue #264 / #275へ記録します。失敗した検証を成功扱いにしません。
