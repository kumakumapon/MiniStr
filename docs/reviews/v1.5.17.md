# v1.5.17 レビュー

固定32×32・全軍敵対・ユーザー1軍・敵CPU3軍を既存の4軍エンジンに接続した。ゲーム規則・CPU v3・経路規則・初期配置を変更せず、命令操作、手番制御、表示と保存メタデータを追加する。通常2軍の戦績には反映しない。

## 実装範囲

- 第1〜第4軍のいずれかを担当し、移動・主副武器攻撃・占領・生産・待機・合流・搭載・降車・手番終了を確認して実行する。命令元の兵科/ID/HPと対象、攻撃予測を表示する。参加対局は盤面に兵科記号を表示する。
- 候補と予測は自軍観測のみを使い、共通エンジンで確定する。失敗時は他命令や手番終了へ置換しない。未知敵接触も既存の経路規則を使用する。
- 敵3軍のCPU処理後は自軍入力を待つ。自軍の手番にWorkerを計画させず、他軍の操作を拒否する。取消・背景化・保存・対局切替後の古い結果を破棄する。
- 生存/未決着なら敵手番とリプレイ中も自軍視界に固定する。自軍脱落で敗北を表示して停止し、残りの観戦を選べる。終局後は命令を無効にする。
- 担当軍付き新形式を専用2枠、JSON、完全履歴検証、リプレイ、全体バックアップに接続する。旧観戦形式/CPU/経路規則を維持し、参加対局と観戦を相互に読み込んでも担当軍・保存視点・停止状態を復元する。

## 公開条件と残件

正式Releaseは、同一mainの通常CI全ゲート・Node22.13互換・CodeQL・Pagesの成功と、配信bundleのversion/SHA・正式タグを照合した上で作成する。実際の公開確認は[PR #308](https://github.com/kumakumapon/MiniStr/pull/308)とReleaseに記録する。

CPUの新規未決着20条件・開始順の公平性はv1.5.16の課題を継続する。本版でCPU比較202回を再実施したとは主張しない。実時間2/4時間の物理端末での連続運転、人間参加での難易度・操作性の実戦評価も継続する。ブラウザー自動テストを物理端末のタッチ/VoiceOver確認として扱わない。[操作・保存仕様](../four-army-human-v1.md)。
