# v1.5.17 レビュー

固定32×32・全軍敵対・ユーザー1軍・敵CPU3軍を、既存の4軍エンジンに接続した。ゲーム規則・CPU判断・経路規則を変更せず、ユーザー操作、手番制御、表示と保存メタデータを追加する。

## 確認対象

- 第1〜第4軍を選択し、自軍視界だけで操作する。敵手番・リプレイ中も生存中の自軍視点を維持する。
- 移動・主副武器攻撃・占領・生産・待機・合流・搭載・降車・手番終了を共通エンジンに適用する。
- 未確定命令の取消、敵3軍後の自軍入力待ち、停止後のWorker結果破棄、背景化・保存・再開を確認する。
- 担当軍付き新形式の完全履歴検証、旧CPU観戦形式との互換、専用2枠・JSON・リプレイ・バックアップを確認する。
- 脱落後に敗北を表示し観戦継続できること、終局後に命令が無効になることを確認する。

## 検証

ローカルの補助環境で関連31テスト、テストを含む型検査、CI条件回帰、private-sessionリンク検査に合格。lockfile指定の正式環境での全件テスト・カバレッジ・UI・実ブラウザー検証は実行後に追記する。

## 残件

CPUの新規未決着20条件・手番順の公平性、実時間2/4時間の実機連続運転、人間参加での難易度・操作性の実戦評価は本版の機能追加と分けて継続する。[操作・保存仕様](../four-army-human-v1.md)。
