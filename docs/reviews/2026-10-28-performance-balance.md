# 性能・CPU／先後バランス評価の拡充

基準main: 7d3833156b040b28585b9958f5cc523fe96a2cd8。追跡: #168（性能・CPU・バランス）、#155、#213。

## 実施計画

1. 通常／32×32盤面、CPU判断、長期対局のリプレイseek、保存一覧を測定。warm-upと複数標本、p50／p95／最大値、実行環境・ソース識別・GCを含むメモリの限界を記録する。
2. 生成マップのサイズ・海域・seed・難易度・軍方針を拡張し、同じ条件で配置を入れ替えた対局を対にして先後と配置の影響を確認する。未決着・打切りを勝利と混同しない。
3. 実測で確認したボトルネックを改善し、同条件の前後比較、決定性・視界制約・保存互換性の回帰を確認する。勝率の小標本だけで補正値を変更しない。
4. 結果・再現コマンド・残る評価範囲を保存し、CI／CodeQL成功後にPRをレビュー可能にする。

現時点は計画のみ。新機能・版番号・保存形式の変更は含めない。iPhone／iPad実機確認と人間の公平感は未確認として区別する。
