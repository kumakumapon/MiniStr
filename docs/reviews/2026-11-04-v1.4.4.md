## 採用した判断修正

### 兵站

補給車の残量だけでなく、実際の手番開始時と同じIDの辞書順で近隣の地上部隊への物資配分を見積もる。非緊急の部隊が先に消費する分も差し引き、対象の主武器弾薬または燃料が増えない補給地点を候補から外す。別の補給車からの転送や敵の将来行動は確約せず、自軍の現在資源による保守的な見積もりである。

移動済み・行動済み補給車の隣で待機させる場合も、配分後の残量と既存の安全評価を再確認する。物資が先に尽きる、または危険と判断した地点で弾切れ部隊を固定しない。搭載中・護衛／撤退対象・固定補給で対応可能な部隊等の既存制約を維持する。

### 守勢の修理

守勢のHP50以下の部隊は、互換性のある自軍施設での有償HP修理を位置評価へ加える。自軍資金＋既知の収入からaffordableRepairを使い、1回最大20HPの2倍を位置評価値にする。補給車・補給所・他兵科の施設・敵施設はHP修理扱いにしない。占領・直接攻撃・支援射撃・撤退目標など既存の判断順序は維持する。旧規則のCPUには新軍方針を適用しない既存境界を保持。

## 比較方法・限界

[全rawのSHA256・header・完了件数・条件別集計・前後対応](v1.4.4/summary.json)を保存した。計25ファイル・352局で、往復・前後・試案・無効試行36局を含む。316局の有効な対局記録があるが、独立した316標本とは扱わない。

- 先攻は常に赤。復路は盤面を180度回転し、難易度と軍方針を交換する。先後・配置・方針の影響は条件別に見る。
- 生成20／32、陸・沿岸・海洋、均衡同士／守勢対攻勢、標準・初級・上級を比較。広域戦線32は支配目標、生成比較は司令部占領等の既存目標を使う。
- 広域戦線32では後攻補償0／2000Gも比較する。公開カタログの2000Gは変更していない。
- カタログのseed文字列は実行の識別名で、地形は変化しない。独立に指定したdamageSeedが戦闘乱数を変える。天候の既存独立streamは維持する。
- `--rounds 90`でも生成マップ自身の60ラウンド判定は維持。広域戦線32は90ラウンド判定。判定まで進んだ結果と短期撃破を区別し、未決着を勝利や引き分けに加算しない。
- CPU時間は複数比較・テストの同時実行下の診断値で、速度改善の根拠にはしない。
- 修理回復量・再補充主弾薬・燃料純増・手番開始時の弾切れ／燃料切れ地上部隊・空物資補給車を記録。施設と補給車の効果を合算し、燃料は消費後の純増である。対局の長さ・生存部隊数も異なるため、合計値の減少をそのまま効率向上率としない。

## CPU試案・最終結果

CPU Aは配分見積もり＋修理評価に、回復する弾数等による補給地点の追加加点を含めた。Bは追加加点を除いて既存の位置評価を維持し、実際に届くかの判定と修理評価を採用した。[A](v1.4.4/cpu-a.patch)／[採用B](v1.4.4/cpu-b.patch)。小標本の勝率だけでなく、補給地点を過度に変えないことを採用理由とした。

| 比較 | 基準→採用B |
| --- | --- |
| generated-holdout：16局中、守勢対攻勢8局 | 守勢3→4勝 |
| generated-confirm：難易度交換を含む24局 | 守勢6→5勝 |
| wide-holdout：12局中、守勢対攻勢6局 | 守勢3→2勝 |
| 最終未使用条件final-generated：16局 | 守勢9→8勝、修理回復5028→5625HP、弾薬／燃料切れの地上部隊開始81→78 |
| 最終未使用条件final-wide：16局中、守勢対攻勢8局 | 守勢4→5勝、全体の修理回復137→225HP、地上部隊開始26→26 |
| 同上・均衡同士8局 | 先攻:後攻5:3を維持、全8局の指令digestも一致 |
| classic：20／32・沿岸の均衡同士4局 | 勝敗・指令digest・兵站指標すべて一致 |

最終生成＋広域の守勢は計13→13勝。勝率の全般的向上は確認していない。空物資補給車の手番開始は最終生成1→0、広域2→0だが、標本が小さく長期・全条件の保証ではない。別の比較では物資不足が増えた条件もある。初級・標準・上級の強さや全マップの公平性を解決済みとしない。

## マップ試案と不採用理由

既存配置が一律に先攻有利とは確認できなかった。広域戦線32の基準wide-holdoutでは均衡同士6局が先攻3・後攻3、最終の補償比較では0Gが2:2／2000Gが3:1だった。条件差と小標本を追跡し、先攻補正を一括変更しない。

- A／B：遮蔽案の探索でcells配列への反映位置を誤り、名前だけ変更されていた。A16局＋B8局＋B-holdout12局の36局は地形案の評価として無効。rawを削除せず、採否から除外する。[Aソース](v1.4.4/map-a-source.txt)／[Bパッチ](v1.4.4/map-b.patch)。
- C：配列への反映を修正し、中央に対称な森林6マスを追加。[パッチ](v1.4.4/map-c.patch)。wide-holdoutの均衡は3:3→2:4、守勢対攻勢は先攻2:後攻4→先攻6:後攻0となり、不採用。守勢の勝数だけなら3を維持するが、先後の偏りを隠さない。
- D：広域戦線32だけ追加補給所2か所を作らず、元の得点対象2か所へ限定。[パッチ](v1.4.4/map-d.patch)。同条件の均衡3:3は維持するが守勢3→1勝に悪化し、不採用。

**公開するマップ配置・目標・名称はv1.4.3のまま。** CPUと配置を同時に変えて改善と誤認することを避け、今回の比較ではCPU判断修正だけを採用した。守勢・兵站の長期計画、wide-frontの問題条件、別配置・戦闘乱数を継続する。
