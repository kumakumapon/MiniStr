# 遅れて来る列強の参入とCPU評価

18×14。北、西、東の3軍は第1ラウンドから戦う。南の出発地点を割り当てられた軍は、第8ラウンドから参入できる。見ることができる情報は予約区域・予定ラウンド・資金・部隊・チーム。参入前の視界、部隊、手番、収入、補給は発生しない。

ラウンド境界で南の区域が空いていれば、司令部・工場・都市2か所、初期資金15,000Gと6部隊を追加する。区域に他軍の部隊や所有拠点があると参加を延期し、次の境界で再判定する。保留表示から未視認部隊の位置は分からない。参入時に過去の収入を加えず、最初の手番で通常の開始処理を一度行う。先行3軍だけで決着した場合もそこで終局する。

配置版10、match 3、engine 6、内側schema 6（four-army-v6）、外側schema 7。予約と参入ラウンドを保存し、採用した初期条件から命令列を再生して検証する。未参入軍で開始して保存・再開できる。新しい形式はこの戦域に適用する。

## 検証

試作の広い区域では、南への進軍や拠点確保のたびに参入が止まった。区域を盤面南端の2行に絞り、峠の手前に争える中立都市を追加した。第8ラウンド参入、占有が続いた場合の保留、解消後の次ラウンド参入、初期視点と保存互換をテストした。

調整seed 341349と分け、評価seed 341353で初期手番24順列・地点割当2通り・戦術OFF/ONを比較した。CPU v7、普通・均衡、短期戦。
