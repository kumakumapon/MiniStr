# v1.1.0 実装計画（#244 / #245）

対象基準: v1.0.0 / 971ea082651e8c4e0ad1fe818238bc7cba2d0bbd。

1. 広域偵察は既存の各軍2回・半径3・手番中のみを継続し、追加ルールの重複を避ける。視認境界と保存・リプレイを回帰確認する。
2. ルールv12で工兵による隣接した仮設橋の撤去を追加。未移動・未行動、空き橋のみ、行動消費、旧ルール不可。UI・CPU・履歴再生・不正入力を確認する。
3. CPU軍方針を選択できるようにし、難易度と独立した傾向を保存・再開できるようにする。旧対局のCPU判断を維持する。
4. 名前付き継続部隊と分岐キャンペーンを追加。旧キャンペーン進行の移行と入力検証を確認する。
5. 1.xの互換性方針、最新監査、#168/#155の採否、公開前確認を記録する。
6. 全作戦攻略、旧ルール比較、単体・UI・ブラウザ・静的検査・ビルドを確認してから1.1.0への版更新とリリースノートを完成させる。

各機能を個別コミット・PRでレビューし、v1.1.0の公開準備は全項目の完了後に行う。未完了項目を実装済みとしてIssueを閉じない。
