# v1.4.1 計画

## 対象

CPUの守勢・連携・兵站とマップの先後バランス、32×32の実ユニット選択・初回表示・復帰の応答を改善する。保存の完全同時書き込み排他は今回の対象に含めない。

## 手順

1. 計画だけでドラフトPRを作成後、v1.4.0を基準に計測する。
2. CPUの公開情報・合法性・決定性・処理予算を維持し、守勢の損失判断と支援・拠点競争を検討。既存マップ・生成seed・旧保存の規則を保持する。
3. 先後交換・未使用seed・20／32盤面・陸海・CPU方針を比較し、改善が確認できた変更を採用する。不採用案も記録する。
4. 実際の部隊選択と初回表示をPC／390幅で測定し、観戦指令と区別する。描画・計算の重複を削減し、情報境界・入力・フォーカスを回帰確認する。
5. 回帰テスト、型・lint・整形・coverage・build・ブラウザ・正式CIを確認する。性能・勝率の全般的改善を小標本から断定しない。
6. package／lockと公開ノートを1.4.1に同期し、結果をIssue #168・#213と確認記録へ記載。検証完了後にPRをレビュー可能にする。マージ後main／Pagesの成功を確認して正式Releaseを公開する。
