# v1.5.0 兵站運用と部隊一覧

## 採用範囲

- 自軍部隊の補給優先（通常／優先）、弾薬／燃料優先、修理実施／保留と軍全体の修理後留保資金を指定する。
- 操作は自軍手番のコマンドとして記録し、保存・取り消し・リプレイに対応。旧対局は旧配分を維持する。新しい独立兵站ルールを通常・統合戦術に適用し、旧アプリで安全に拒否する版を使用する。
- 部隊一覧は行動済み・搭載部隊も含み、損傷・弾薬不足・燃料不足・補給見通しを表示。選択すると盤面上の部隊または輸送先へ移動する。
- 兵站判断を使う単体作戦を1本追加し、既存の保持目標・補給車・対応施設を活用する。
- CPUも同じコマンド・物資制約を使い、自軍と可視情報だけで運用を指定する。

## 検証と公開

補給競合、燃料優先、修理保留と資金下限、不正コマンド、旧版拒否／旧対局再現、保存・リプレイ・CPUの合法性、作戦攻略、日英と390幅の一覧操作を確認。型・lint・format・coverage・build・ブラウザと正式CIを確認する。v1.5.0の公開文書と版番号を用意し、最終検証後にDraftを解除する。

計画のみのDraft PRを先に作成する。マージと正式Release公開は利用者が行う。
