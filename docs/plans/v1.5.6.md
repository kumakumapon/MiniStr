# v1.5.6: 護衛失敗と操作応答

基準は公開v1.5.5/main 053a22c22b286c5d59051b485a38b734a21112ce。Issue #264・#275の旧2（残る護衛失敗）と旧3（操作応答）を扱う。

護衛はconvoy-escort・標準ON・seed15411・赤hard/青easyのT3 r1喪失を再現する。雨天で視界が狭い場合、近くの前衛装甲部隊から離れる前進を、既存の合法・安全評価に通る代替位置から選び直す。既知の敵への危険評価・退避を優先し、旧規則/OFF、撤退、晴天、後退、孤立した対象、即時脱出を維持する。非可視の敵位置や私的な資源を使わない。

操作応答は390幅・32盤面を含め、初回選択、キーボード移動、復帰、兵站一覧を計測する。対局状態・視点・言語・操作権・絞り込み・開閉が同じ場合だけ一覧の見込み計算とDOMを保持し、選択表示を更新する。状態が変われば作り直す。保持される盤面は再描画前にフォーカスし、置換後の補正と既存のスクロール復元を保護する。

既知96条件、26作戦ON/OFFの52条件、候補固定後の未使用32条件を比較する。記録済み敗北・新しい勝利のリプレイと保存再開、旧規則/OFF、他作戦の回帰を確認する。

ローカルの補助ビルド・利用可能なブラウザーでの確認と、指定依存版のVite配布ビルドでの確認を区別する。固定した同じ依存とharnessで3ブラウザーを逐次実行し、変更前後の順序を交互にした3組の比較を残す。計測ホストではCPU対局・別ブラウザー検証を同時に走らせない。フレーム値はスケジューリングを含む代理値で、実機のタッチ遅延やGPU描画完了を保証しない。絶対時間のCI閾値は追加しない。

ゲーム規則、マップ、ルールv14、対局保存/リプレイschema4、campaign schema5、依存版、既存CI/Pages条件は変更しない。計測用workflowは専用ブランチに置く。実装PRの全品質ゲート、マージ後main CI/CodeQL、Pagesと正式タグ/Releaseのversion・SHA一致を確認し、v1.5.6として公開する。
