# v1.5.7 出撃前配置

基準: 公開v1.5.6/main ffe87428a4f9941024ed19b98e75938cbb081e9f。Issue #264旧7・#275の出撃前配置を、2軍の単体作戦1本へ導入する。

対象は現行カタログの「峡谷の関門」（20×16）と標準の統合戦術版。キャンペーン、日替わり、編集/読込マップ、他作戦、旧12×10版の配置変更には広げない。

表示座標は1始まり。赤軍X1〜4/Y2〜5、青軍X17〜20/Y12〜15の4×4区域を180度回転で対応させる。各軍の地上4枠を移動可能とし、航空枠r5/b5の位置は固定。兵科選択・予算・必須占領兵科・開始時補償は既存規則を使う。固定位置と兵科の固定を区別し、航空枠の兵科変更は従来どおりとする。

自軍区域・整数座標・通行可能地形・重複と固定位置を確認する。配列を並べ替えず、初期部隊IDと確定配置をscenario snapshotへ保存する。CPU対戦では赤だけ、交代対戦/CPU観戦では両軍を編集可能とし、CPU対戦へ切り替えた場合の青軍は既定配置とする。

UIは各枠の出撃位置選択と4×4区域プレビュー。1軍の位置だけのリセットと、従来の編成全体リセットを用意する。既存の兵科プリセットは位置を保存しない。適用時にその軍の位置だけ既定へ戻し、既存schema1を維持する。

既定配置と従来の準備処理の一致、区域/固定/予算/ID、保存再開/命令再生、日英・1280/390幅・キーボード・プリセット/モード変更・対象外作戦を検証する。26作戦ON/OFFの52条件は公開v1.5.6の命令digestと比較。配置6種類×ON/OFF×2seed×先後の48条件を別記録し、配置による損失・到達・捕獲・収入・対局長の変化を確認する。相関する対局数を独立の勝率推定としない。

ゲームの戦闘/勝敗規則・AI・地形・ルールv14・保存/リプレイschema4・campaign schema5・依存・既存CI/Pages条件は変更しない。全品質ゲートとmain CI/CodeQL、Pages・タグ/Releaseのversion/SHA一致を確認してv1.5.7として公開する。
