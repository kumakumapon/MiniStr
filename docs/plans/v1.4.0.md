# v1.4.0 implementation plan

Issue #213. Baseline: v1.3.0, 51bfe19bc2cfc09288374c886e93bdde37d3a61a.

## Scope

- Versioned tactical rules: simultaneous adjacent direct fire, explicit mutual terminal outcome, prepared ambush, restrained ground terrain bonus.
- Public-information CPU planning for attrition, coordination, transport, ZOC, weather and antisubmarine warfare.
- Versioned tactical map layouts with alternatives, staged objectives and supply.
- Shared observation and deterministic movement events for weather, ZOC and submerged contacts.
- Submarine with surface/submerge actions, explicit detection and counterweapons.
- Move then unload for APC, landing ship and transport helicopter; passenger and transport finish their action.
- Japanese/English controls, predictions, battle results, saves, undo and replay.
- Package/release notes for v1.4.0, unit/UI/browser regression and bounded balance comparisons.

## Compatibility and delivery

Introduce an opt-in combined tactical preset for normal/single-operation games. Preserve old match snapshots and rule versions. Keep campaign/daily standard records on their recorded settings. No direct main changes.

Create this plan-only draft PR before product changes. Complete implementation and evidence, then mark ready for review. User merges; release v1.4.0 from the merged verified commit.

## Evaluation

Compare old/current rules, maps and CPU separately before the combined preset. Record map/combat/weather seeds, first/second cohorts, outcomes (including draws/undecided), transport/ambush/detection events and response bounds. Treat limited CPU results as diagnostics, not universal fairness proof.

Network policy currently permits only cdn.playwright.dev. Reuse installed tooling for local diagnostics; clean locked dependency checks run in GitHub CI if registry access remains unavailable.
