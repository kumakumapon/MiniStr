# v0.9.4 実装計画

## 採用範囲

- タイトルの戦域サムネイルと盤面の地形表示を同じ見た目に揃える。全5テーマ・地形・施設・生成／カスタム作戦を確認する。
- 赤軍／青軍の手番に応じてフィールドBGMを切り替える。両軍の曲を設定でき、共通曲にも戻せるようにする。戦闘専用BGM、単一音声要素、iOSのジェスチャー解除と非同期競合対策を維持する。
- ロック調のオリジナルBGMを2曲追加し、生成方法・長さ・ライセンスを記録する。既存の曲は保持する。
- タイトルからBGMのオン／オフ・音量・陣営別の曲を設定でき、対局中の設定と同期して保存する。既存設定は音量・ミュート・選択曲を維持して移行する。
- Issue #213の新案として、テーマに対応した地形凡例を盤面近くへ折り畳み表示する。地形の見分けと補給所・橋の意味を確認しやすくする。
- ゲーム規則v10・保存／リプレイschema4・シナリオ・戦績は維持し、バージョンとリリースノートを0.9.4へ更新する。

## 確認と公開

- 関連単体・UI統合・保存設定互換・ブラウザ回帰を追加・実行する。全テーマのサムネイル／盤面比較、陣営交代・戦闘からの復帰・連続戦闘・リプレイ・観戦・ミュート・音量0・設定保存を確認する。
- lint・形式・型・カバレッジ・ビルド・リンク・PC／スマートフォン幅の画面を確認する。音源の形式・長さ・音量・ループ接続を確認し、実機iPhone／iPadは別途の未確認事項として明記する。
- ドラフトPRを先に作ってから実装し、CI・CodeQLの成功後にレビュー可能へ変更する。マージ後にmainのCI・Pagesを確認し、そのコミットをv0.9.4の公開対象とする。
