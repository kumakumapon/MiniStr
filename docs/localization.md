# 表示言語

タイトルなどの「言語 / Language」で日本語・英語を切り替えます。設定はブラウザへ保存し、保存領域が使えない場合は現在のタブに適用します。

## v0.9.2の対応範囲

- タイトル、生成設定、作戦準備・出撃前編成・プリセット、対局操作、ユニット情報、生産、索敵・補給・架橋・設営、戦績・観戦分析、キャンペーン、保存・リプレイ・エディタ。
- 通知、確認・名前入力ダイアログ、ツールチップ、読み上げ用ラベル、選択肢のグループ名。
- 組み込み作戦・練習・キャンペーンの名前と説明、標準の生成戦域v1/v2と前線v3の表示用メタデータ。
- 英語時の盤面兵科記号と階級名。日本語へ戻すと元の記号・名称を表示します。

利用者が入力したセーブ名・プリセット名・カスタム作戦名・本文、JSON欄、IDは翻訳しません。英語モードでこれらに日本語が表示される場合は、入力された内容を保持した表示です。組み込み作戦も表示時に翻訳し、保存済みシナリオの定義を書き換えません。OSやブラウザが提供するファイル選択画面などの言語は、それぞれの設定に従います。

## 実装の境界

- `src/ui/english.ts`：既存の日本語表示文に対応する英語リソース。`{0}`などの引数は原文と同じ集合を維持します。
- `unitNameText.ts`：兵科名の日本語・英語を共有します。CPU行動履歴は表示言語に依存しない文で保持し、表示時に翻訳するため、途中の言語切り替えにも追従します。
- `translateText`：UI文の翻訳。差し込まれた名前・IDは再翻訳しません。
- `translateGameText`：アプリが生成した説明や表示値の合成専用。利用者の自由文を渡しません。
- `scenarioText.ts`：組み込み・キャンペーン・標準の生成文を照合したうえで表示だけを翻訳します。カスタム名・説明は保持します。勝敗条件の説明もUI側で翻訳します。
- `localizeControls`：DOMの文字列と`aria-label`・`title`・`alt`・`placeholder`・`label`を反映します。後から生成するエディタの選択肢も含め、描画処理の最後に実行します。
- `data-ui-copy`：合成されたアプリ専用の文言に指定します。配下に名前を含む通知がある場合は`data-user-copy`で再翻訳を防ぎます。`data-user-content`は利用者の本文を保持し、`data-user-attributes`で指定した属性も保持します。フォーム値やtextarea内のJSONは変更しません。

新しい画面では、静的ラベルだけでなく、動的な通知・属性・一覧・確認ダイアログも確認してください。英訳が未知の文言は削除・隠蔽せず元の表示を残します。

## 回帰確認

- リソースの英語本文・引数、動的メッセージ、利用者名の保持、日本語への復帰、兵科記号・階級名。
- 全組み込み作戦・キャンペーン・生成方式v1/v2/v3の表示と、シナリオ定義が変更されないこと。
- 配布用ビルドで全組み込み作戦の準備画面、練習・生産・保存・キャンペーン・エディタ、言語往復と保存データの保持。
- Chromium・Firefox・WebKitでPC／スマートフォン幅の画面遷移・ダイアログ・横方向のはみ出し。実機iPhone／iPadの操作確認とは別の検証です。
