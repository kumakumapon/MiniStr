# 4軍の操作・自由割当・陸戦規則（v1.5.19）

## 対象と開始

固定32×32「四方の前線」・4軍全参加・全軍敵対、各軍8部隊・基本資金10,000・搭載込み16部隊上限を維持する。開始方式は従来の1軍操作／全軍CPU観戦に加え、「軍ごとに自由設定」を選べる。各軍を人間またはCPUに指定し、人間0〜4軍の16通りを扱う。同じ人が複数軍を操作する場合も、複数人で交代する場合も同じ引渡し手順を使う。操作種別は同盟を意味しない。

新規対局は拡張規則と陸戦統合戦術を初期選択する。開始前に「従来の4軍規則」を選ぶことも、拡張規則だけを使い陸戦戦術をOFFにすることもできる。軍別CPU難易度／方針、seed、手番順は既存機能を使う。開始後の人間／CPU割当は固定する。

## 操作改善

生産ダイアログで施設を切り替え、価格・移動・射程・資金不足・部隊上限・施設条件を確認できる。生産後は次の空き施設へ進み、空き施設がなければ閉じる。Esc／閉じるは命令を実行せず施設へ戻る。

敵別の主／副武器・反撃予測を一覧で確認できる。「予測を確認」は対象へフォーカスするだけで攻撃しない。直接攻撃は従来どおり部隊→敵の操作を使う。移動後も選択を保持する。未行動一覧と終了確認は盤上の未行動部隊を対象とし、搭載中の部隊だけでは確認を出さない。占領残値・地形防御・補給範囲・経験階級・設営陣地も表示する。観測情報と計算結果を保持し、フォーカス移動だけでは兵站一覧を作り直さない。

## 入力・CPU・引渡し

人間手番では現在軍だけが命令できる。CPU手番は現在軍の観測だけをWorkerへ渡し、CPUが続く区間を進め、次の人間手番で止まる。停止・読込・画面変更・対局置換でWorkerを取消し、世代・手番・要求の一致を再確認する。

複数人間軍では各人間手番の開始時に引渡し画面を出す。盤面、カード、命令欄、部隊一覧、予測、モバイル操作、選択、フォーカスを前の軍から持ち越さない。間のCPU手番も中立画面にする。人間1軍では従来どおりその軍の視界でCPU手番を見られる。

人間軍が残る間は全体／他軍への視点切替を拒否する。複数人間軍の対局中は履歴リプレイを開かず、保存・再開を使う。1軍だけの脱落では他の人間軍へ進み、全人間軍が脱落すると停止し、明示操作で残りのCPUを観戦できる。100ラウンドの区切りと読込は停止状態を維持する。

## 新しい陸戦規則

- 広域偵察：各軍2回、半径3。現在軍の手番だけ視界を拡張し、手番終了時に範囲を消す。残回数は軍別に保持する。
- 陣地設営：未移動・未行動の工兵が平原に500Gで設営する。各軍4か所まで。費用と行動消費を確認し、他軍の地上部隊の進入で陣地を除く。
- 兵站指示：部隊別の補給優先・弾薬／燃料優先・修理実施／保留、軍別の修理留保資金を使う。搭載部隊を含む一覧・絞り込み・現配置での次手番見込みは2軍と同じ部品を使う。2軍画面とID・一覧状態を分離する。
- 陸戦統合戦術：同時射撃・待伏せ・地形防御・天候・ZOCを2軍の計算へ接続する。待伏せは主／副武器を選び、未知敵との実接触で1回解決する。準備は次の自軍手番で解除する。天候はラウンドで共有する。

軍の所有権は常に第1〜第4軍を保持する。各命令の計算時だけ行為軍と他軍へ投影し、陣地・偵察回数・予算を実際の軍IDへ戻す。軍別の上限、機密情報、脱落・最後の1軍勝利、初回燃料免除、開始済み手番の再開を維持する。移動・未知敵接触の同距離経路は司令部基準の回転対応を使う。

CPU v4はv3の燃料帰還を継承し、新規則で設営・近接待伏せ・接近した司令部の偵察・損傷部隊の補給優先を候補に加える。旧CPU版は保持し、旧保存では明示切替まで変更しない。

## 保存互換

新しい公開保存は `ministr-four-army-configurable`／schema3。4軍すべての人間／CPU割当を必須とし、専用2枠・JSON・リプレイ・全体バックアップへ接続する。旧参加保存は記録された1軍だけを人間、旧観戦は全軍CPUとして扱う。読込時に規則やCPU版を自動更新しない。

新規則は固定マップの新ID、engine3／four-army-v3で記録し、規則・軍別偵察・陣地・修理予算・天候seedを検証する。新命令の辞書／数値列はfour-army-log-v2、従来命令だけの列はv1を保つ。旧engine1／2とCPU v1／2／3、旧経路は従来の状態遷移で再生する。旧アプリは未知の形式／版を拒否する。

新旧とも65,536命令・8MB、専用2枠を維持する。固定初期条件と全履歴から最終状態を照合し、ファイル由来checkpointを信頼しない。未知版・不正値・軍の欠落・許可されない視点・容量不足・取消失敗では現在対局や原本を置き換えない。複数人保存の再開は引渡し画面から始める。

## 後続残件

新20打切り／開始順の公平性、実機・実時間2／4時間、人間参加の実戦評価を継続する。次は保存を伴う目撃履歴、1手戻す／自動保存、敵行動ログ・演出・終局／再戦、2〜4軍の参加設定、途中の人間↔CPU切替を検討する。

水域・港のない現行盤面で架橋・橋破壊・潜航は提供しない。対応盤面、同盟／共有視界／チーム勝利、初期条件調整、任意盤面、通信、研究分岐はそれぞれ別の採用判断とする。
