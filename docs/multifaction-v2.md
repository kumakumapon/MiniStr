# 複数軍対局 v2（v1.5.22）

通常の2軍対戦は既存の入口・マップ・CPU・保存形式を使う。本仕様は「3・4軍対局・観戦」から開始する独立した複数軍モードに適用する。このモード内では2軍も選べる。

## 開始と配置

| マップ         | 実寸  | 初期部隊／搭載込み上限 | 基本資金 |
| -------------- | ----- | ---------------------- | -------- |
| 緑の国境       | 18×14 | 4／8                   | 6,000G   |
| 前哨基地強襲   | 18×14 | 4／8                   | 6,000G   |
| 交差海峡       | 17×15 | 4／8                   | 6,000G   |
| 新・四方の前線 | 32×32 | 8／16                  | 10,000G  |

各マップで第1〜4軍の任意の2〜4軍を参加させる。不参加軍の司令部・部隊・施設・資金・収入・手番・脱落は作らない。予約された4軍分の操作・履歴キーはCPU／空履歴にする。途中参加・退出は今回含めない。

緑の国境の3軍配置は北の開始域を後退し、北の工場を側方へ置く。各軍の初期施設数・部隊・資金は等しい。4軍の地形は上下・左右の鏡像を揃える。前哨基地強襲は中央の拠点と森林を追加する。新広域は独立した配置を持つ。従来の四方の前線32×32は別選択として残り、旧規則・4軍固定を保持する。

## 手番と決着

2軍の順番は固定。新しい3・4軍では初期手番順を毎ラウンド1枠ずつ左にずらす。脱落軍の枠を飛ばし、生存軍は1ラウンドに1回だけ開始処理・収入・行動を受ける。初回の定常燃料免除、100ラウンドの停止を維持する。

短期戦は3軍21R、2・4軍20Rを全生存軍が終えた直後、次の収入・修理の前に判定する。3軍は各初期手番位置7回、4軍は各5回を担当する。所有施設数→残存HPで比較し、首位同点は引分。全ての施設は各1、搭載部隊もHPに含む。「決着まで」も選べる。20〜30分は人間1軍の試遊目標であり、実時間の保証・タイマーではない。

## 固定チーム

個人戦またはA〜Dの固定チームを指定する。チームは2組以上必要で、1対2、2対2、1対1対2などに対応する。チーム表示のIDは参加軍IDと独立したラベルであり、そのラベルの軍を追加しない。

味方への攻撃・占領を禁止し、味方を通過する移動は既存の自軍移動規則に従う。通常の部隊視界と味方の部隊・搭載情報を共有する。資金・収入・施設補給・修理・偵察の回数と効果・兵站・部隊操作は軍別。軍をまたぐ合流・輸送・生産・操作はできない。味方の行動を自軍手番の開始処理でリセットしない。

司令部または全部隊を失った軍は脱落し、その軍の従来どおりの除去・施設中立化を行う。最後の生存チームが勝利する。脱落した味方もチームの勝者に含める。短期判定は同じチームの生存軍の施設数・HPを合算する。途中の同盟変更・外交・個別降伏は含めない。

## 水域の初版

交差海峡の2・4軍は四分割の陸地と1マス幅の十字海峡、3軍は三つの島と中央島を持つ。港・既設橋・中立拠点を配置する。各軍は歩兵2（うち1は搭載）・揚陸艦1・工兵1（3軍のみ駆逐艦1）で開始する。港を含めた初回収入は各軍4,000G。

水上艦の移動・戦闘、上陸、港での生産・修理・有限燃料と弾薬を使う。既設橋は所有軍脱落後も残り、水上艦は下を航行できる。工兵は未移動・未行動で、隣接する1マス幅の水域へ1,000Gで架橋する。既設分を含め各軍2橋まで。見えている空の橋を隣接工兵で破壊でき、建設・破壊は全行動を消費する。味方の橋の破壊も可能なので操作で対象を確認する。潜水艦・潜航・共有補給艦は含めない。

## 対局中の操作担当

「操作担当を変更」から生存している参加軍を人間／CPUへ切り替える。まずCPU進行と保留中Workerを取消し、同じ状態・命令列で停止する。手番・資金・燃料・残り行動を更新しない。変更後に人間の現手番を開く際は引渡し画面を挟む。新たな命令は自分の軍だけに出せる。undoを消去し、独立自動保存へ直ちに保存する。保存競合時の変更は禁止する。

担当変更は最大256件。命令数と軍、変更前後の担当を記録し、同じ命令位置で複数軍を順番に変更できる。旧対局のCPU版は担当変更だけでは変えず、CPU改善版への明示切替は別操作とする。変更履歴のある進行中対局は過去の視界を開く再生を禁止し、終局後は再生可能。再戦は現在の担当を新しい初期担当とし、履歴を空にする。

## 保存と互換

新配置はmatch2／layout2・engine5／four-army-v5・経路3・CPU v6・外側schema6。schema6は初期担当・変更履歴・現在担当を持つ。建設・破壊を含む命令列はlog-v3で表せる。全合法命令を初期マップから再生し、担当変更時点の生存・担当・終局状態と最終担当も検証する。ファイル内チェックポイントを権威として使わない。上限は65,536命令・8MB、全体backup40MBを維持する。

v1.5.21の小型map1／engine4／経路2／CPU v5／schema5と、それ以前の広域対局を当時の規則で読む。旧保存の明示的な担当変更やCPU変更はschema6へ保存でき、過去の命令を改変しない。通常2軍・campaignの戦績へ反映しない。

## CPU v6の限定変更

3軍では公開された施設所有数を使い、優先相手を拠点最多の敵へ向ける。同数時は司令部位置の循環順で決め、どの敵とも通常どおり交戦する。非占領部隊が敵施設付近を往復して終局が進まない条件に対し、生存2軍・40R以降に戦闘部隊の進軍先を敵司令部へ向ける。健康な占領部隊は、既知の地形経路が燃料内に収まる補給可能な敵施設を目指せる。帰還・損傷時の修理は維持する。水域の工兵は隣接する合法な橋の建設を候補にできる。

部隊能力・相手資金・隠れた部隊・実戦乱数はCPUへ追加公開しない。v1〜5の判断経路と旧保存の再現は維持する。比較結果と未解消条件は[評価記録](reviews/v1.5.22.md)で区別する。
