# 渡河・生成戦域拡張（Issue #213）

基準: v0.9.0 / c3e6dd94de39a0e9903028cf7a8836fdd7fdbbfa。
この設計だけのコミットでドラフトPRを作成し、その後に実装する。

## 採用範囲

1. 工兵が隣接する1マスの海へ仮設橋を建設する。未移動・未行動、視認済み空きマス、対向する通行可能な岸、1000G、各軍2か所を初期値とする。建設で行動終了。橋は両軍で利用可能、対局終了まで残り、位置は公開する。元の海と艦船通行を保持し、1マス1部隊を継続する。
2. 生成マップへ「前線補給・工兵」の選択を追加する。補給所と工兵を対称配置し、旧標準生成v1/v2とseedを保持する。新設定は生成v3として記録する。内陸河川の自動生成は別段階。
3. 「橋頭堡を確保せよ」「対岸への撤退」の単体作戦2本。既存の保持・撤退目標と迂回路を使い、編成・戦績・チャレンジへ接続する。
4. CPUの建設・移動・護衛・経路の詰まりを改善し、先後・配置方向・難易度・生成seedを分けて評価する。

## 設計条件

- 新規対局はルールv9。旧ルールで橋・新しいCPU判断を使用しない。
- 橋は地形を上書きせず状態へ保存する。通行規則をコマンド・CPU・表示・輸送・入力検証で統一する。
- 完成した橋の位置は両軍に公開し、敵部隊は従来の視界規則を維持する。CPUは既知の敵情報だけを使う。
- 橋の建設命令・保存・取り消し・リプレイ・視点回転・エディタを整合させる。旧セーブと保存済み作戦の再現性を保持する。
- 建設可能位置・費用・通行条件、確認・中止・Escを盤面付近に表示する。部隊情報を盤面から遠ざけない。
- 橋の破壊、撤去、複数マス架橋、補給車の物資在庫、軍方針、キャンペーン追加は本PRの対象外。
