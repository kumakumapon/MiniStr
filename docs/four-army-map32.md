# 4軍専用32盤面・初期条件・部隊上限（v1.5.12）

「四方の前線」`four-fronts-32-v1`を追加した。v1.5.11のCPU/取消APIから実際に進行できる固定マップsnapshotで、開始メニューと観戦画面の接続は次段階。最初のプレイ可能な4軍CPU観戦には、観戦画面と公開用保存/リプレイ/バックアップも揃える。

## 盤面と開始条件

32×32の陸上・航空向けマップ1本。北西の区画を90度ずつ回転し、地形・施設・開始域・部隊を4軍へ同じ条件で配置する。道路で4方面と中央を結び、森と山を置く。海・港・初期航空部隊はない。自軍空港で航空機を生産できる。単体作戦、生成マップ、2軍の既存配置へ混ぜない。

座標は以下のみ内部の0始まりで示す。

| 軍 | 元司令部 | 開始域（両端を含む） |
| --- | --- | --- |
| army1 | (3,3) | X1〜9 / Y1〜9 |
| army2 | (28,3) | X22〜30 / Y1〜9 |
| army3 | (28,28) | X22〜30 / Y22〜30 |
| army4 | (3,28) | X1〜9 / Y22〜30 |

各軍は歩兵3・偵察車1・戦車1・自走砲1・補給車1・対空車両1の**8部隊**、合計32部隊で開始する。HP100、燃料・主/副弾薬は満量、補給車の有限物資は300。搭載中部隊はない。固定ID・初期配列・seed・指定手番順をsnapshotへ記録する。軍IDと手番順を同一視しない。

各軍の所有施設は司令部1・工場1・空港1・都市2。基本資金10,000、基本income0を全軍へ同じく記録し、各軍の初回手番開始時に5,000の収入を1回だけ加える。先頭軍だけ開幕資金を加算しない。全軍の初回維持燃料免除と有償修理/有限補給は既存4軍エンジンの順序を維持する。中立施設は工場4・都市4で、いずれの開始域にも含めない。

開始域は初期配置の検証に使い、対局開始後の移動を区域内へ制限しない。搭載した初期部隊の位置は同軍の輸送元で検証する。公開マップの固定初期配置を自由編集する画面は本版に含めない。

## 上限

このマップの上限は**各軍16、合計64部隊**。盤上・搭載中を合算する。上限に達した軍の生産をCPUと実エンジンの両方で拒否し、失敗時は資金・部隊・履歴を進めない。合流や損失で枠が空けば再び生産できる。脱落軍の空き枠を他軍へ移さない。

CPUの生産目安はeasy7・normal11・hard16で、初期8部隊を難易度で削らない。実エンジンの16枠は全難易度共通。従来の上限指定のない4軍観測は旧CPUの生産目安を保ち、2軍の上限は変更しない。

8・12・16/軍（総32・48・64）について、満員の開始域と中央接触の合成盤面、全4軍・normal/hardのCPU判断と命令適用、Chromium/Firefox/WebKitの実Worker往復・取消を比較する。16は比較した最大候補から選ぶ運用上限で、端末の限界値や全条件の最適値ではない。[測定条件と結果](reviews/2026-11-13-v1.5.12.md)。

## 保存と入力の境界

- 新マップはengineVersion2。`setup`にversion1・軍別上限・4開始域を保持する。区域の重なり・盤外・司令部の区域外・初期部隊の区域外・上限超過を拒否する。CPU観測には公開上限だけを追加し、敵の隠れた配置や資金は渡さない。
- 4軍チェックポイントはschema2 / `four-army-v2`。上限と開始域を含む元マップ・命令履歴・stateを照合して再開する。版とrulesetの不一致、上限だけを改ざんしたstate/マップを拒否する。
- v1.5.10/11のsetupを持たない4軍マップ・state・schema1 / `four-army-v1`を旧経路で読める。旧コンテナを新ルールへ自動変換しない。旧アプリはschema2を拒否する。通常2軍schema4・研究schema1・キャンペーンschema5は変更しない。
- これはエンジンのJSONチェックポイント。軍別CPU設定・観戦状態の永続化、名前付き保存、公開JSON操作/リプレイ、長い命令列とバックアップは次段階。現行の1MB/2048命令境界は維持する。

## 次の4陣営残件

1. 開始メニュー・観戦画面：軍識別/情報/視点、難易度・方針、速度、停止/再開、100ラウンド停止を接続する。
2. 公開用保存・JSON操作・リプレイ・バックアップ：軍別CPU設定と算法版、長い命令列、名前付き保存を接続し、既存通常/研究保存を守る。
3. 公開判定：全手番順・配置/seed/方針/難易度の対局結果、同じ総部隊数の2軍/4軍のCPU時間・入力応答・長期メモリ、従来2軍の退行を比較する。

90度対称と初期収入の一致だけで対局の公平性を保証しない。今回の短い合成計測を、実機・長期観戦や4軍の勝率/難易度順の検証完了とは扱わない。旧4全体は、マップ/初期条件/上限までの部分完了を維持する。
