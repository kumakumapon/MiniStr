# 4軍の経路規則と燃料帰還（v1.5.16）

同距離経路を絶対y/x順で復元していたため、同じ正規化局面・移動先でも未知敵との接触位置と燃料が分かれていた。新規4軍対局の固定32盤面はmap/stateに`pathVersion: 1`を記録し、公開された自軍司令部からの座標で同距離の前駆マスを選ぶ。通常移動・接触停止の経路復元に同じ基準を使う。戦闘乱数や2軍の経路規則は変更しない。

旧map/stateはフィールド省略を旧規則として維持する。履歴再生・続行・チェックポイントは保存時の規則を使用し、自動的に経路版を変えない。旧CPU v1/v2も引き続き選べる。「改善版CPUへ切り替え」は過去のprefix/state/乱数/経路規則を保ち、今後のCPU判断だけをv3へ変える。新経路を使うには新規対局を開始する。未知のpathVersion、map/stateの版の不一致・履歴改ざんを拒否し、原本を保持する。旧アプリは新しいフィールドを拒否する。公開保存schema2・65,536命令/8MBと完全な履歴照合・取消・バックアップの境界は維持する。

未決着14条件では燃料枯渇・帰還しない判断を再現して調査する。CPU v3は公開された自軍補給施設までの地形距離を求め、残燃料が「帰還距離+移動力2回分」以下なら帰路を優先する。占領・確実な攻撃等の既存優先度と視界外生産の安全な後回しを保ち、隠れた敵占有や乱数は参照しない。CPU v1/v2の分岐にはこの評価を適用しない。過去の比較CLIはCPU v2へ固定し、新版は`four-army:path-compare`を使う。

候補固定後の202回：v1.5.15で測定済みの144条件の新版、全24順のseed15161と混合4順seed15163の新旧56回、旧CPU v1/v2の既知case hash一致2回。400/1,000ラウンド・65,536命令の予算を維持し、未決着を引き分けに変換しない。
