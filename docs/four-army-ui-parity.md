# 4軍UIの2軍操作統一（v1.5.18）

## 採用仕様

固定32×32・全軍敵対・ユーザー1軍・敵CPU3軍の規則は変更しない。2軍の軍事地図調（暗い緑のフレーム、金色の操作強調、既存の地形・部隊画像、system-ui）と画面部品を共用する。PCは盤面と右の命令パネル、スマートフォンは盤面を先に置き、主要操作を画面下に常設する。保存・CPU設定・視点・言語など使用頻度の低い情報は折り畳み、CPU再生／停止は独立させる。

- 自軍部隊をクリック／タップして選択。到達可能な空きマスを押すと直ちに移動し、選択を維持する。視認済みの敵を押すと攻撃する。命令ごとの確認段階は廃止する。
- 攻撃武器は2軍と同じ部隊カードで「自動（最大ダメージ）／主武器／副武器」を指定する。フォーカスした攻撃対象の予測ダメージを表示する。予測・経路・目標表示は自軍の観測情報だけから計算する。
- 待機・占領は選択中の部隊への直接操作。合流・搭載・降車は明示した操作の後に対象マスを押す。無効なマスを押しても命令・乱数・手番を消費しない。
- 選択中の自軍部隊がないとき、空いている自軍生産施設を押すと生産メニューを開く。価格・資金・上限を示し、可能な部隊だけを選べる。閉じる／Escでは命令せず施設へフォーカスを戻す。
- 未行動部隊の一覧と「次の未行動部隊」を用意する。矢印／Home／Endはマスのフォーカス移動、Enter／Spaceはそのマスの操作、Nは次の未行動部隊、Escは選択・対象指定の取消。CPU観戦・再生中のEscは停止する。
- 未行動部隊が残っているときのターン終了確認は初期状態で有効。取消では履歴を増やさない。敵手番とリプレイでは自軍命令を受け付けない。
- 盤面は2軍のDOMボタン・画像・選択枠・移動範囲・索敵外表示を共用する。初期マス幅44px、拡大率50／75／100／125／150／200%。32盤面は内側を縦横スクロールする。縮小表示はユーザーが明示した場合に限る。軍は色だけでなく番号・名称でも区別する。
- 選択部隊の耐久・燃料・弾薬・行動状態を盤面上のカードで確認できる。敵の兵站情報と索敵外部隊を表示しない。選択部隊を維持したまま目的地をキーボードで調べられる。CPU更新で盤面ボタンを保持し、フォーカスと押下先を失わない。

## 影響範囲と検証

UI操作と表示だけを変更し、ゲーム規則・CPU判断版・保存schema・長期記録上限・公開条件は変更しない。従来の4軍対局／観戦保存は同じ読み込み検証を通し、停止状態・操作軍・視点・履歴を保持する。通常の2軍画面には4軍専用CSSを適用しない。

PC／スマートフォン・日本語／英語・4軍それぞれの操作、キーボードの直接移動と選択取消、武器指定、輸送、生産、CPU手番、保存再読込、リプレイの読み取り専用を検証する。既存の通常対局・観戦・Worker取消・保存互換の回帰検証を維持する。
