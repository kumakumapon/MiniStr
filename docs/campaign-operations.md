# 国境戦役：作戦と部隊継承

## 設計の狙い

通常戦を順番に遊ぶ形式から、補給線の確立、戦線突破、防衛と再編、総反攻という4戦域の連続作戦へ変更する。補給と生還部隊の経験が次の出撃へつながる。

大戦略シリーズの公式説明を参考に、複数戦場の攻略と経験の持ち越し、出撃前の準備という考え方をMiniStr向けに採用した。

- [大戦略VII EXCEED：キャンペーンモード](https://www.ss-beta.co.jp/products/ds7ex/new.html)
- [大戦略 大東亜興亡史：インターミッション](https://www.ss-beta.co.jp/products/daitoa_psp/system3.html)

作戦・音楽・文章・実装はMiniStr独自。今回の進行は従来の解放順を維持する。

## 作戦目標

座標は画面と同じ1始まり。保持目標は、**全指定地点に自軍の配置済み部隊がいる状態で自軍ターンを終了**すると1進む。自軍ターン終了時に一つでも空いていれば0に戻る。施設の所有だけでは保持に含めない。すべての作戦は敵司令部の占領でも勝利する。

通常戦の対称マップや勝敗条件は変更せず、キャンペーン開始時に専用条件を持つシナリオのスナップショットを生成する。旧セーブで再開した作戦は、記録当時の条件を維持する。

## 出撃準備と補給支援

- 作戦選択で目標・期限・支援・経験継承候補数を示し、ブリーフィングで補給方針を確認する。
- 直前作戦の最高評価に応じて、赤軍だけに一度限りの出撃資金を加える：S = 2000G、A = 1500G、B = 1000G、C = 500G。第1作戦は0G。
- 支援は毎回の出撃条件として計算し、残金を積み立てる方式にはしない。再挑戦によって支援総額が増えることはない。
- 初期資金の表示は初回収入と支援を含む実際の赤軍開始資金。
- 作戦中の収入・生産・弾薬補給・有料修理は既存の近代ルールを使う。修理と増援の資金配分が必要になる。

## 経験継承

- 勝利時の赤軍生還部隊を記録する。輸送中の部隊も含め、上限64部隊。
- 各生還部隊は戦闘で得た経験に従軍分の1を加え、既存の上限10で記録する。
- 次作戦の同種の初期部隊へ、高い経験から一対一で割り当てる。部隊数・兵種・配置は作戦の既定枠を使う。同種の枠がない候補は出撃しない。
- 出撃時は耐久100・燃料満タン・弾薬満タンに再編する。経験に応じた階級効果は既存の戦闘ルールを使う。
- 継承元は直前作戦のみ。その作戦の最新の勝利で生還記録を置き換えるため、同じ作戦を再挑戦しても、自分自身の記録に経験を加算し続けることはない。
- 敗北時は新しい評価・解放・経験を記録せず、同じ作戦を再挑戦できる。

## 保存と互換性

- キャンペーン進行はschema v4。v1〜v3の解放済み作戦と最高評価を保持して移行する。過去の生還部隊は記録がないので、移行後の勝利から蓄積する。
- 経験記録は既知の兵種・整数1〜10・クリア済み作戦・64部隊以内で検証する。従来のサイズ上限、解放順・評価の整合性検査も維持する。
- 出撃支援と初期経験はシナリオのスナップショットに固定する。途中で以前の作戦の成績が変わっても、進行中の対局・セーブ・リプレイの戦力は変わらない。
- 対局セーブとリプレイは既存schema v4を使用。スナップショットの初期資金・経験も含め、正規の初期状態とコマンド再生による検証を維持する。
