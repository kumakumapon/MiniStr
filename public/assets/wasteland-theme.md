# Wasteland theme

`wasteland-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
外部の楽曲や録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 72 BPM、ホ短調、16小節、約53.3秒のループ（西部劇風の渋い曲調）
- 低いドローン、爪弾くギター風アルペジオ、口笛風の疎なリード、深いトム、後半に控えめなブラシ
- 8・16小節目に短いトムのフィル
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約690 KiB
- 生成: `scripts/generate-music.mjs`
