# Dawn theme

`dawn-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
外部の楽曲や録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 84 BPM、ニ長調、16小節、約45.7秒のループ（希望に満ちた讃歌調）
- 低音のホルン、フルート風の旋律、4声の弦パッド、ハープ風アルペジオ（後半は16分に増える）
- 柔らかいティンパニと、大きなホール風の残響。ループ境界で尾が折り返される
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約560 KiB
- 生成: `scripts/generate-music.mjs`
