# Battle theme

`battle-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
既存ゲームの楽曲や外部の録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 200 BPM、ニ短調、1.95秒のワンショット（ループしない）
- 立ち上がりの速い金管の上昇フレーズ、16分音符の低音、キック・スネアロール
- 1.2秒でニ短調の和音と低音の決め打ちに着地し、残響を含めて約2.05秒のバトル演出内で完結
- 音源末尾を冒頭に折り返さず、最後の180 msで消音。前奏なしで開始し、途中の反復なし
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約28.5 KiB。エンコード時に -4.9 dB 調整
- 生成: 出力用ディレクトリで `node /path/to/scripts/generate-music.mjs battle`、続けて `ffmpeg -i battle.wav -af volume=-4.9dB -c:a libvorbis -q:a 3 battle-theme.ogg`
- 戦闘曲の乱数シードを固定しているため、他の曲の生成順に依存しない

戦闘開始時に冒頭から1回再生します。演出の差し替え時も冒頭に戻り、終了・スキップ時には通常曲の続きへ戻ります。
発射・着弾・撃破の効果音は音源に混ぜず、Web Audio でアニメーションに合わせて再生します。
