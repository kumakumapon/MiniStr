# Drive theme

`drive-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
外部の楽曲や録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 128 BPM、イ短調、16小節、30秒のループ（シンセとドラムのエレクトロ調）
- 四つ打ちキック、16分のハイハット、クラップ、転がるシンセベース、裏拍のコードスタブ、16分のアルペジオ、後半のリード旋律
- 8・16小節目にライザーとスネアロール
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約420 KiB
- 生成: `scripts/generate-music.mjs`
