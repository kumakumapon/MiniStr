# Mist theme

`mist-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
外部の楽曲や録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 60 BPM、ヘ長調系、16小節、64秒のループ（静かなアンビエント）
- ゆっくり変わる4声の弦パッド、サブ、ベル風の旋律とエコー、ごく控えめな太鼓
- 深い残響。ループ境界で尾が折り返され、つなぎ目が目立たない
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約780 KiB
- 生成: `scripts/generate-music.mjs`
