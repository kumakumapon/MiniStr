# Frontier theme

`frontier-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
外部の楽曲や録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 100 BPM、ニ短調、16小節、38.4秒のループ（行進曲風の疾走感）
- ホルンの付点リズムの旋律（オクターブ重ね。後半は高音のトランペット風を追加）
- 低弦の刻み（前半は8分、後半は16分）、サブベースの8分パルス、弦パッド、ハープ風アルペジオ
- 太鼓・キック・軽いスネアの行進リズム、4小節ごとのシンバル、8・16小節目のスネアロール
- ステレオの残響。ループ境界で尾が折り返され、つなぎ目が目立たない
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約520 KiB
- 生成: `scripts/generate-music.mjs`
