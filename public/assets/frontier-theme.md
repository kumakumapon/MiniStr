# Frontier theme

`frontier-theme.ogg` は MiniStr 用に作曲・合成したオリジナル音源です。
外部の楽曲や録音サンプルは使用していません。リポジトリと同じ MIT ライセンスで配布します。

- 76 BPM、ニ短調、16小節、約50.5秒のループ
- 広がる弦のパッド、コントラバスの持続低音、ホルンの旋律（後半は3声）、ハープ風アルペジオ、ティンパニ
- 大きめのホールの残響。ループ境界で尾が折り返され、つなぎ目が目立たない
- Ogg Vorbis / 44.1 kHz / stereo / quality 3、約640 KiB
- 生成: `scripts/generate-music.mjs`
