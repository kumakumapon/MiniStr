# MiniStr

**[▶ ブラウザーで遊ぶ（GitHub Pages）](https://kumakumapon.github.io/MiniStr/)**

MiniStrは、地形・視界・補給を考えながら部隊を動かすターン制戦略ゲームです。拠点を占領して収入と生産拠点を確保し、戦域ごとの勝利条件を達成します。PC・スマートフォンのブラウザーで遊べます。

## 遊び方

| 遊びたいこと | タイトル画面からの始め方 |
| --- | --- |
| 基本操作を試す | 「基本操作を練習」で移動・攻撃・占領・補給・生産・輸送を練習します。 |
| 通常の2軍対局 | 戦域カードを選び、ブリーフィングでCPU対戦、2人対戦（1台で交代）、観戦（CPU同士）を選びます。 |
| キャンペーン | 「キャンペーン」で解放済みの作戦を選びます。戦果と生還部隊の経験を引き継ぎます。 [作戦仕様](docs/campaign-operations.md) |
| 小型・広域の3／4軍対局 | タイトルの戦域一覧から選びます。「緑の国境」「前哨基地強襲」は参加軍数・規則を切り替えられます。「交差海峡」「新・四方の前線」「四方の前線」も同じ一覧にあります。 [複数軍の規則](docs/multifaction-v2.md) |
| CPUの対局を観戦する | 通常2軍はブリーフィングで「観戦（CPU同士）」、複数軍は開始条件で「CPU観戦」を選びます。対局中に一時停止や速度変更ができます。 |

## 操作方法

1. 自軍の部隊をクリックまたはタップします。移動先のマスや見えている敵を選び、攻撃前には戦闘予測を確認します。
2. 歩兵などで対象の拠点に入り、「占領」を選びます。空いている自軍工場・空港・港湾では部隊を生産できます。
3. 操作を終えたら「ターン終了」を押します。端末を交代する対戦では、引渡し画面で次のプレイヤーに端末を渡してください。

キーボードは矢印キーで盤面を移動、Enter／Spaceで選択・実行、Escで選択解除です。スマートフォンでは下部のクイック操作バーと盤面の拡大・縮小を使えます。 [表示と観戦の操作](docs/ui-controls.md)

## 主な特徴

- **戦術と補給**。霧の中で偵察し、地形・射程・燃料・弾薬を見ながら戦います。輸送部隊や工兵で進軍路を確保できます。 [前線補給](docs/frontline-logistics.md)・[渡河](docs/river-crossing.md)
- **対局の保存と再生**。タイトルの「続きから」で通常2軍・複数軍・研究の保存を選び、「記録を開く」でJSONを読み込めます。全データのバックアップはJSONに書き出せます。 [保存と互換性](docs/persistence-schema.md)・[研究対局](docs/research-matches.md)
- **マップ編集と日替わり**。「マップ編集」で地形・初期部隊・目標を組み合わせ、「今日の戦域」で日替わり対局を始められます。 [マップ生成と単体作戦](docs/standalone-systems.md)・[日替わりチャレンジ](docs/daily-challenge.md)
- **表示・演出設定**。日本語／英語、盤面倍率、バトルシーン、占領・補給演出、BGMや効果音を設定できます。 [地形表示と音楽](docs/presentation-and-music.md)

## 開発

Node.js 22.13以降の22系または24系、npm 10〜12を使用します。

```sh
git clone https://github.com/kumakumapon/MiniStr.git
cd MiniStr
npm ci
npm run dev
```

TypeScriptとViteを使用します。`src/game/` はゲーム規則・状態・保存、`src/ai/` はCPUの判断、`src/ui/` は画面・操作・演出を担当し、`src/main.ts` がアプリを起動します。個別モジュールと調査の起点は実装ガイドにまとめています。 [実装ガイド](docs/implementation-guide.md)

## CIとデプロイ

プルリクエストと `main` で書式・型・lint・依存監査、Vitest、Playwrightの3ブラウザー検証、Node 22.13互換を確認します。GitHub Pagesには、`main` の全検証に成功した実行で生成したビルドを公開します。 [CIと依存関係の運用](docs/ci-maintenance.md)・[検証コマンド](docs/implementation-guide.md#10-開発検証)

## 既知の制限

- 保存や設定は利用中のブラウザーに保持されます。端末を移すときやブラウザーのデータを消去する前は、全データをJSONへ書き出してください。 [保存仕様](docs/persistence-schema.md)
- 3軍の戦術ON時の勝敗の偏り、水域・広域の長期戦の一部、実機での所要時間は引き続き評価中です。 [複数軍の評価記録](docs/reviews/v1.5.25.md)・[対応残件 #275](https://github.com/kumakumapon/MiniStr/issues/275)
